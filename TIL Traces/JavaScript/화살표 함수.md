# 화살표 함수
# 1. 화살표 함수의 선언

- 화살표 함수는 function 키워드 대신 화살표 (⇒)를 사용하여 간략한 방법으로 함수를 선언할 수 있음
- 모든 경우에 사용할 수 있는 것은 아님

## 함수 선언 방법

```jsx
// 1. 매개변수 지정 방법
    () => { ... } // 매개변수가 없을 경우
     x => { ... } // 매개변수가 한 개인 경우, 소괄호를 생략할 수 있다.
(x, y) => { ... } // 매개변수가 여러 개인 경우, 소괄호를 생략할 수 없다.

// 2. 함수 몸체 지정 방법
x => { return x * x }  // single line block
x => x * x             // 함수 몸체가 한줄의 구문이라면 중괄호를 생략할 수 있으며 암묵적으로 return된다. 위 표현과 동일하다.
// return을 생략했으면 중괄호는 반드시 생략해야함

() => { return { a: 1 }; }
() => ({ a: 1 })  // 위 표현과 동일하다. 객체 반환시 소괄호를 사용한다.

() => {           // multi line block.
  const x = 10;
  return x * x;
};

```

# 2. 화살표 함수의 호출

- 화살표 함수는 익명 함수로만 사용할 수 있음
- 화살표 함수를 호출하기 위해서는 함수 표현식을 사용함

```jsx
// 함수 표현식
var pow = function (x) { return x * x; };
console.log(pow(10)); // 100

// 함수 표현식, 화살표 함수
const pow = x => x * x;
console.log(pow(10)); // 100
```

- 화살표 함수는 콜백 함수로 사용할 수 있으며 일반적인 함수 표현식보다 표현이 간결함

```jsx
// 함수 표현식
var arr = [1, 2, 3];
var pow = arr.map(function (x) { // x는 요소값
  return x * x;
});

console.log(pow); // [ 1, 4, 9 ]

// 화살표 함수
const arr = [1, 2, 3];
const pow = arr.map(x => x * x);

console.log(pow); // [ 1, 4, 9 ]

```

# 3. 일반 함수와 차이점

1. 화살표 함수는 인스턴트를 생성할 수 없습니다. 즉, 생성자 함수로 사용할 수 없습니다.
    - 화살표 함수는 non-constructor이며 `prototype` 속성이 없고, 프로토타입도 생성하지 않음
    
    ```jsx
    const Person = (name) => {
        this.name = name;
    };
    
    const john = new Person("John"); // 에러 발생: Person is not a constructor
    ```
    
    ```jsx
    const Person = (name) => {
        this.name = name;
    };
    
    console.log(Person.hasOwnProperty("prototype")); // false
    ```
    
    [자바스크립트 prototype 상속](https://www.notion.so/prototype-80e62eb87dea4b328a5242718b7fdfb1?pvs=21)
    
2. 화살표 함수는 자신만의 this를 가지지 않습니다.
    
    ```jsx
    <!DOCTYPE html>
    <html>
        <head>
            <title>Event Listener Example</title>
        </head>
        <body>
            <button id="myButton">Click Me</button>
            <script src="event.js"></script>
        </body>
    </html>
    ```
    
    ```jsx
    const myButton = document.getElementById('myButton');
    
    // 일반 함수를 사용한 이벤트 핸들러
    myButton.addEventListener("click", function() {
        console.log("Clicked using normal function. This: " + this.textContent);
    }); // A?
    
    // 화살표 함수를 사용한 이벤트 핸들러
    myButton.addEventListener("click", () => {
        console.log("Clicked using arrow function. This text: " + this.textContent);
    }); // B?
    ```
    
    - 답
        
        ```jsx
        const myButton = document.getElementById('myButton');
        
        // 일반 함수를 사용한 이벤트 핸들러
        myButton.addEventListener("click", function() {
            console.log("Clicked using normal function. This: " + this.textContent);
        }); // Click Me
        
        // 화살표 함수를 사용한 이벤트 핸들러
        myButton.addEventListener("click", () => {
            console.log("Clicked using arrow function. This text: " + this.textContent);
        }); // Clicked using arrow function. This text: undefined
        
        ```
        
    - 이벤트 핸들러 내에서 `this`가 필요한 경우에는 일반 함수를 사용하는 것이 적합하며, 화살표 함수를 사용할 경우 주의해야 함
    - 화살표 함수는 주로 `this`를 사용하지 않거나, 외부 스코프에서의 `this`를 그대로 사용할 때 유용
3. 화살표 함수는 arguments 객체를 가지지 않습니다.
    
    ```jsx
    function sumWithArguments() {
        let sum = 0;
        
        for (let i = 0; i < arguments.length; i++) {
            sum += arguments[i];
        }
        
        return sum;
    }
    
    const sumWithArrow = () => {
        let sum = 0;
        
        for (let i = 0; i < arguments.length; i++) {
            sum += arguments[i]; // 여기서 arguments를 사용하면 에러가 발생합니다.
        }
        
        return sum;
    }
    
    console.log(sumWithArguments(1, 2, 3, 4, 5)); // 출력: 15
    console.log(sumWithArrow(1, 2, 3, 4, 5)); // 에러 발생: arguments is not defined
    ```
    
    - `arguments` 객체는 함수 내에서 인수에 접근하는 데 사용되는데, 일반 함수에서는 이 객체를 사용할 수 있지만 화살표 함수에서는 사용할 수 없음
        
        <aside>
        💡
        
        `arguments`는 자바스크립트에서 함수 내부에서 사용할 수 있는 특별한 객체입니다. 이 객체는 함수로 전달된 모든 인수를 배열처럼 접근할 수 있게 해주지만, 실제 배열은 아닙니다. 이를 통해 함수에 전달된 인수들을 개수에 상관없이 다룰 수 있습니다.
        
        - `arguments`의 특징
        1. **배열처럼 접근 가능**: `arguments` 객체는 배열과 비슷하게 인덱스를 사용하여 개별 인수에 접근할 수 있지만, 실제 배열은 아닙니다. 예를 들어, `arguments[0]`은 첫 번째 인수, `arguments[1]`은 두 번째 인수 등을 나타냅니다.
        2. **`length` 속성**: `arguments` 객체는 `length` 속성을 가지고 있어서 전달된 인수의 개수를 나타냅니다.
        3. **함수 스코프 내에서만 사용 가능**: `arguments`는 함수 내부에서만 사용할 수 있습니다. 함수 바깥에서는 사용할 수 없습니다.
        </aside>
        

# 4. this

## 4.1 일반 함수의 this

- 자바스크립트의 경우 함수 호출 방식에 의해 [this](https://poiemaweb.com/js-this)에 바인딩할 어떤 객체가 동적으로 결정
- **함수를 호출할 때 함수가 어떻게 호출되었는지에 따라** this에 바인딩할 객체가 동적으로 결정

 

```jsx
function Prefixer(prefix) {
  this.prefix = prefix;
}

Prefixer.prototype.prefixArray = function (arr) {
  // (A) this = pre
  return arr.map(function (x) {
    return this.prefix + ' ' + x; // (B) undefined
  });
};

var pre = new Prefixer('Hi');
console.log(pre.prefixArray(['Lee', 'Kim']));
```

- 콜백 함수 내부의 this는 전역 객체 window를 가리킨다.
- (A) 지점에서의 this는 생성자 함수 Prefixer가 생성한 객체, 즉 생성자 함수의 인스턴스(위 예제의 경우 pre)임
- (B) 지점에서 this는 전역 객체 window를 가리킨다.

<aside>
💡

생성자 함수와 객체의 메소드를 제외한 모든 함수(내부 함수, 콜백 함수 포함) 내부의 this는 전역 객체를 가리키기 때문이다.

</aside>

## 4.2 콜백 함수 내부 this가 메소드를 호출한 객체를 가르키게 하는 방법 3가지

```jsx
// Solution 1: that = this
function Prefixer(prefix) {
  this.prefix = prefix;
}

Prefixer.prototype.prefixArray = function (arr) {
// 콜백함수로 들어가기 전 that을 먼저 할당해줌
  var that = this;  // this: Prefixer 생성자 함수의 인스턴스
  return arr.map(function (x) {
    return that.prefix + ' ' + x;
  });
};

var pre = new Prefixer('Hi');
console.log(pre.prefixArray(['Lee', 'Kim']));
```

```jsx
// Solution 2: map(func, this)
function Prefixer(prefix) {
  this.prefix = prefix;
}

Prefixer.prototype.prefixArray = function (arr) {
  return arr.map(function (x) {
    return this.prefix + ' ' + x; // 여기서 `this`는 `prefixArray`를 호출한 객체, 즉 `Prefixer`의 인스턴스를 가리킵니다.
  }, this); // this: Prefixer 생성자 함수의 인스턴스, `map`의 두 번째 인수로 `this`를 전달합니다.
};

var pre = new Prefixer('Hi');
console.log(pre.prefixArray(['Lee', 'Kim']));
```

```jsx
// Solution 3: bind(this)
function Prefixer(prefix) {
  this.prefix = prefix;
}

Prefixer.prototype.prefixArray = function (arr) {
  return arr.map(function (x) {
    return this.prefix + ' ' + x;
  }.bind(this)); // this: Prefixer 생성자 함수의 인스턴스
};

var pre = new Prefixer('Hi');
console.log(pre.prefixArray(['Lee', 'Kim']));
```

## 4.3 화살표 함수의 this

- 화살표 함수는 함수를 선언할 때 this에 바인딩할 객체가 정적으로 결정됨
- 동적으로 결정되는 일반 함수와 달리 화살표 함수의 this는 언제나 상위 스코프의 this를 가르킴 ⇒ ``Lexical this``

```jsx
function Prefixer(prefix) {
  this.prefix = prefix;
}

Prefixer.prototype.prefixArray = function (arr) {
  // this는 상위 스코프인 prefixArray 메소드 내의 this를 가리킨다.
  return arr.map(x => `${this.prefix}  ${x}`);
};

const pre = new Prefixer('Hi');
console.log(pre.prefixArray(['Lee', 'Kim']));
```

# 4. 화살표 함수를 쓰는 이유

- 메소드 내부에서 화살표 함수를 사용하면, 화살표 함수는 자신만의 `this`를 가지지 않고, 상위 스코프의 `this`를 상속받기 때문에 `this` 관련 문제를 피하고 코드를 간결하게 작성할 수 있음

```jsx
const myObj = {
    name: "홍길동",
    func: function() {
        console.log(this.name); // 출력: "홍길동", myObj의 메서드로 호출됨
        
        /* 일반 함수를 사용 */
        setTimeout(function() {
            console.log(this); // 출력: window 객체
            console.log(this.name); // error 출력되지 않음
        }, 1000);
        
        /* 일반 함수를 사용 */
        setTimeout(function() {
            console.log(this); // 출력: myObj 객체
            console.log(this.name); // 출력: "홍길동"
        }.bind(this), 1000); // bind() 함수로 this를 myObj 객체로 설정해야 하는 번거로움이 있음
    },
    arrow_func: function() {
        console.log(this.name); // 출력: "홍길동"
        
         /* 화살표 함수를 사용 */
        setTimeout(() => {
            console.log(this); // 출력: myObj 객체
            console.log(this.name); // 출력: "홍길동"
        }, 1000);
    } 
}

myObj.func();
myObj.arrow_func();
```

- 화살표 함수 `() => {}`는 렉시컬 스코프(lexical scoping)를 따릅니다. 즉, 화살표 함수는 자신이 정의된 위치의 `this`를 그대로 가져옵니다.
