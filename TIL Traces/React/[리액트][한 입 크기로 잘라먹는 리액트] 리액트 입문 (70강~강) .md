## UseReducer
- 컴포넌트 내부에 새로운 State를 생성하는 React Hook
- 모든 useState는 useReducer로 대체 가능
- State 생성은 컴포넌트 내부에서 하고 컴포넌트 외부에서 상태 관리 코드를 구분해서 작성할 수 있음
  - State 생성 코드
  - 상태 관리 함수

- 컴포넌트의 메인 역할은 UI를 렌더링하기 위한 코드 작성
  => State로 인해 상태 관리하는 코드들이 길어진다면 주객전도되는 것
