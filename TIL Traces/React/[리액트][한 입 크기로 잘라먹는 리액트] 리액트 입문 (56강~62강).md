### React Hooks

- React Hooks : 클래스 컴포넌트의 기능을 함수 컴포넌트에서도 이용할 수 있도록 도와주는 메소드
  - 모든 기능을 이용할 수 있는 클래스 컴포넌트(문법 복잡)와 다르게 함수 컴포넌트는 UI 렌더링만 할 수 있었음
  - 이를 해결하기 위해 React Hooks 개발함
    => 특별한 경우가 아니면 이제 함수 컴포넌트로 코드를 작성
- 지금까지 배운 useState, useRef 모두 React Hooks였음
- React Hooks의 메소드는 use라는 접두사가 쓰임

  - 예 : useEffect, useReducer, useRef, useState...

- 조건문, 반복문 내부에서는 호출이 불가
- 함수 컴포넌트 내부에서만 호출 가능

### React Hook 3가지 팁

1. 함수 컴포넌트, 커스텀 훅 내부에서만 호출 가능
2. 조건부로 호출될 수는 없다. => 호출 순서가 꼬이면서 순서가 엉망이 됨
3. 나만의 훅(custom Hook)을 직접 만들 수 있다.

### Custom Hook

1. custom hook 경로 : src/hooks/
2. custom hook 생성의 경우 함수를 만들 때 함수 이름 앞에 'use'를 추가함 => 자동으로 리액트가 커스텀 훅으로 인식
3. 동일한 컴포넌트. state를 여러개 만들어야 하는 경우 함수를 활용해서 이를 불러와서 생성할 수 있게 하면 편하다.
   1. 이때 useState와 같이 내부에 React Hook을 사용하면 함수를 Custom Hook으로 만들어주면서 컴포넌트 함수로 만들어서 사용 가능하다.
      => 일반적인 함수에서 React Hook을 사용 불가능함, 컴포넌트 내부에서만 사용 가능

- useInput.jsx

```
import { useState } from "react"

// 커스텀 훅으로 변경하는 방법 : 함수 이름 앞에 use 접두사 사용
function useInput(){
  // 리액트 컴포넌트나 커스텀 훅 내부에서만 사용 가능함
  const [input, setInput] = useState("")

  const onChange = (e)=>{
    setInput(e.target.value)}

  return [input, onChange]
}

export default useInput
```

- HookExam.jsx

```
import useInput from "../hooks/useInput"

const HookExam = ()=>{
  const [input, onChange] = useInput()
  const [input2, onChange2] = useInput()

    <input value={input2} type="text" onChange={onChange2} />
    {input}

  </div>

  )}

export default HookExam
```

### 카운트 앱 생성하기 (State Lifting)
1. React의 경우 모든 데이터의 흐름이 위에서 아래로 가는 단방향 데이터 흐름을 가지고 있음
2. 따라서 아래에서 옆으로 가거나 아래에서 위로 갈 수 없기에 여러 컴포넌트에서 사용해야하는 데이터는 함께 사용하는 가장 상단으로 끌어올려져야 함
   => 이를 State Lifting 이라고 부름
3. 데이터를 아래로 넘길 때 State 변수나 함수를 넘길 수도 있지만 상위에 State가 있기 때문에 State 함수를 통한 <u>**이벤트 핸들러 자체를 정의하여 props로 넘길 수 있음**</u>
  => 이렇게 되는 경우 하위 컴포넌트의 태그 속성에서 해당 이벤트 핸들러와 인자를 넣어주기만 하면 해당 이벤트가 진행되게 할 수 있음


- App.jsx

```
import { useState } from "react";
import "./App.css";
import Viewer from "./components/Viewer";
import Controller from "./components/Controller";

// 모든 데이터들은 가장 상단으로 끌어올려져야 함 => State lifting
// 위에서 아래로 단방향 데이터 흐름을 가지고 있음
function App() {
  const [count, setCount] = useState(0);
  // 이벤트 핸들러 자체를 만들어서 그걸 그대로 props로 넘기는 방법이 있음
  const onClickButton=(value)=>{
    setCount(count+value)
  }

  return (
    <div className="App">
      <h1>Simple Counter</h1>
      <section>
        <Viewer count={count}/>
      </section>
      <section>
        <Controller onClickButton={onClickButton}/>
      </section>
    </div>
  );
}

export default App;

```

### LifeCycle
#### LifeCycle이란?
- 생애 주기

| Mount                          | Update                           | UnMount                               |
|--------------------------------|----------------------------------|---------------------------------------|
| 컴포넌트가 탄생하는 순간, 화면에 처음 렌더링되는 순간 | 컴포넌트가 다시 렌더링 되는 순간, 리렌더링 될 때를 의미 | 컴포넌트가 화면에서 사라지는 순간, 렌더링에서 제외되는 순간을 의미 |

=> LifeCycle에 따라 제어하는 경우 useEffect를 사용

### useEffect
1. 리액트 컴포넌트의 사이드 이펙트를 제어하는 새로운 React Hook
  - 리액트에서 사이드 이펙트란 "부수적인 효과", "파생되는 효과" 정도로 해석
  - ex) 과식을 하면 살이 찐다 => 과식을 한 것에서 파생되는 효과인 살이 찐다가 사이드 이펙트
2. 컴포넌트의 동작에 따라 파생되는 여러 효과
   - LifeCycle에 따라서 특정 행동을 하게 하는 것도 컴포넌트 동장에 따라 파생되는 효과
   - useEffect를 통해 제어할 수 있음

#### useEffect 사용법
1. useEffect를 import 한다. (useState와 동일하게 react 위치)
2. useEffect의 인자에는 두개가 존재한다.
   1. 첫번째 인자 : 콜백함수 => 두번째 인자인 의존성 배열이 변경되면 실행됨
   2. 두번째 인자 : 의존성 배열(dependency array, deps) => 배열의 값은 여러개가 들어갈 수 있음
      - 의존성 배열의 값이 변경되면 콜백함수가 실행됨
```
  // 두번째 인자로 들어있는 배열이 변경되면, 첫번째 인자인 콜백함수를 실행시켜줌
  // 두번째 인자로 넘긴 배열에 의존함 => 두번째 인자를 의존성 배열(dependency array, deps)이라고 부름
  // deps 배열의 값은 여러개 들어갈 수 있음
  useEffect(()=>{
    console.log(`count: ${count} / input: ${input}`)
  }, [count, input])
```

#### LifeCycle에 맞춰 useEffect 사용해보기
1. 마운트 : 탄생
   - `useEffect(()=>{
    console.log("mount")
  },[])`
   - deps를 빈 배열로 주면 됨
1. 업데이트 : 변화, 리렌더링
     - `useEffect(()=>{
    if(!isMount.current){
      isMount.current = true
      return
    }
    console.log("update")
  })`
     - deps를 생략하게 되면 변경될 때마다 업데이트
     - 기본적으로 mount, update 상황에서 콜백함수 실행
     - mount인 경우를 제외하고 싶으면 아래 코드와 같이 flag를 세워서 return으로 조절
1. 언마운트 : 죽음
   - `useEffect(()=>{
        return ()=>{
            console.log("unmount")
        }
    },[])`
    - useEffect가 반환하는 콜백함수를 정리함수, 클린업이라고 부름
    - deps를 빈배열로 넣어주면 mount 시 useEffect가 실행되며, mount가 끝날 때 return에 적힌 콜백함수(정리함수, 클린업)이 실행됨

```
const isMount = useRef(false)

  // 1. 마운트 : 탄생
  // 마운트의 경우 처음 연결될 때만 실행되기에 이후 다른 게 변경되어도 실행되지 않음, deps로 빈 배열을 넘기면 됨
  useEffect(()=>{
    console.log("mount")
  },[])

  // 2. 업데이트 : 변화, 리렌더링
  // deps 생략 시 처음 마운트할 때와 리렌더링될 때마다 콜백함수 실행
  useEffect(()=>{
    // mount 시 console이 찍히지 않고 리렌더링 시에만 console을 찍고 싶은 경우
    // useRef를 통해 Mount 여부를 저장하는 변수를 만들고 mount 여부를 바꿔주고 return을 통해 콜백함수를 나가게 함으로써 업데이트 되지 않고 Mount만 된 경우에는 console이 찍히지 않게 함
    if(!isMount.current){
      isMount.current = true
      return
    }
    console.log("update")
  })

```
```
// 3. 언마운트 : 죽음
import { useEffect } from "react"

const Even = ()=>{
    useEffect(()=>{
        // useEffect가 반환하는 함수를 클린업, 정리함수라고 함
        // useEffect가 끝날 때 실행됨
        // deps를 빈 배열로 주면 mount 됐을 때 useEffect가 실행되고 mount가 끝날 때 return 되는 클린업, 정리함수가 실행됨
        return ()=>{
            console.log("unmount")
        }
    },[])

    return <div>짝수입니다.</div>
}

export default Even
```
