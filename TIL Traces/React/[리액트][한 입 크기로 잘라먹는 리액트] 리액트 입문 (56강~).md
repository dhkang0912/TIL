### React Hooks

- React Hooks : 클래스 컴포넌트의 기능을 함수 컴포넌트에서도 이용할 수 있도록 도와주는 메소드
  - 모든 기능을 이용할 수 있는 클래스 컴포넌트(문법 복잡)와 다르게 함수 컴포넌트는 UI 렌더링만 할 수 있었음
  - 이를 해결하기 위해 React Hooks 개발함
    => 특별한 경우가 아니면 이제 함수 컴포넌트로 코드를 작성
- 지금까지 배운 useState, useRef 모두 React Hooks였음
- React Hooks의 메소드는 use라는 접두사가 쓰임

  - 예 : useEffect, useReducer, useRef, useState...

- 조건문, 반복문 내부에서는 호출이 불가
- 함수 컴포넌트 내부에서만 호출 가능

### React Hook 3가지 팁

1. 함수 컴포넌트, 커스텀 훅 내부에서만 호출 가능
2. 조건부로 호출될 수는 없다. => 호출 순서가 꼬이면서 순서가 엉망이 됨
3. 나만의 훅(custom Hook)을 직접 만들 수 있다.

### Custom Hook

1. custom hook 경로 : src/hooks/
2. custom hook 생성의 경우 함수를 만들 때 함수 이름 앞에 'use'를 추가함 => 자동으로 리액트가 커스텀 훅으로 인식
3. 동일한 컴포넌트. state를 여러개 만들어야 하는 경우 함수를 활용해서 이를 불러와서 생성할 수 있게 하면 편하다.
   1. 이때 useState와 같이 내부에 React Hook을 사용하면 함수를 Custom Hook으로 만들어주면서 컴포넌트 함수로 만들어서 사용 가능하다.
      => 일반적인 함수에서 React Hook을 사용 불가능함, 컴포넌트 내부에서만 사용 가능

- useInput.jsx

```
import { useState } from "react"

// 커스텀 훅으로 변경하는 방법 : 함수 이름 앞에 use 접두사 사용
function useInput(){
  // 리액트 컴포넌트나 커스텀 훅 내부에서만 사용 가능함
  const [input, setInput] = useState("")

  const onChange = (e)=>{
    setInput(e.target.value)}

  return [input, onChange]
}

export default useInput
```

- HookExam.jsx


### 카운트 앱 생성하기 (State Lifting)
1. React의 경우 모든 데이터의 흐름이 위에서 아래로 가는 단방향 데이터 흐름을 가지고 있음
2. 따라서 아래에서 옆으로 가거나 아래에서 위로 갈 수 없기에 여러 컴포넌트에서 사용해야하는 데이터는 함께 사용하는 가장 상단으로 끌어올려져야 함
   => 이를 State Lifting 이라고 부름
3. 데이터를 아래로 넘길 때 State 변수나 함수를 넘길 수도 있지만 상위에 State가 있기 때문에 State 함수를 통한 <u>**이벤트 핸들러 자체를 정의하여 props로 넘길 수 있음**</u>
  => 이렇게 되는 경우 하위 컴포넌트의 태그 속성에서 해당 이벤트 핸들러와 인자를 넣어주기만 하면 해당 이벤트가 진행되게 할 수 있음


- App.jsx

```
import { useState } from "react";
import "./App.css";
import Viewer from "./components/Viewer";
import Controller from "./components/Controller";

// 모든 데이터들은 가장 상단으로 끌어올려져야 함 => State lifting
// 위에서 아래로 단방향 데이터 흐름을 가지고 있음
function App() {
  const [count, setCount] = useState(0);
  // 이벤트 핸들러 자체를 만들어서 그걸 그대로 props로 넘기는 방법이 있음
  const onClickButton=(value)=>{
    setCount(count+value)
  }

  return (
    <div className="App">
      <h1>Simple Counter</h1>
      <section>
        <Viewer count={count}/>
      </section>
      <section>
        <Controller onClickButton={onClickButton}/>
      </section>
    </div>
  );
}

export default App;

```

### LifeCycle
1. LifeCycle이란?
- 생애 주기

| Mount                          | Update                           | UnMount                               |
|--------------------------------|----------------------------------|---------------------------------------|
| 컴포넌트가 탄생하는 순간, 화면에 처음 렌더링되는 순간 | 컴포넌트가 다시 렌더링 되는 순간, 리렌더링 될 때를 의미 | 컴포넌트가 화면에서 사라지는 순간, 렌더링에서 제외되는 순간을 의미 |

=> LifeCycle에 따라 제어하는 경우 useEffect를 사용
