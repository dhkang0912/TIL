# 4장 조건에 따라 흐름 바꾸기: 조건문
## 4.1 조건이 하나일 때: if-else
- 조건문 : 조건에 따라 실행하는 명령
  - ```
    if (조건) {
        실행문; // 조건을 만족할 때 실행할 명령문
    } else {
        실행문; // 조건을 만족하지 않을 때 실행할 명령문
    }
    ```
  - 조건을 만족하지 않을 때 실행할 명령문이 없으면 else 블록은 생략해도 됨
  - 실행할 명령문이 하나일 때는 중괄호를 생략해도 됨
    - 예시
    ```java
    if (score > 90)
        System.out.println("A학점");
    else
        System.out.println("A학점이 아닙니다");
    ```

### 4.1.1 조건을 만족할 때
- 예시 : 점수가 90점 이상이면 'A학점입니다.'를 출력
```java
public class Main {
    public static void main(String[] args) {
        int score = 90;
        if (score >= 90){
            System.out.println("A학점입니다.");
        }
    }
}
```
- 실행 결과
```
A학점입니다.
```

### 4.1.2 조건을 만족하지 않을 때
- 조건에 만족하지 않을 때 수행할 명령문 추가

public class Main {

            System.out.println("A학점입니다.");

        }
    }
}
```

- 실행 결과

A학점이 아닙니다.

### 4.1.3 비교 연산자
- 비교 연산자 : 연산자 왼쪽과 오른쪽을 비교

| 연산자 |                설명                |
| :----: | :--------------------------------: |
|   ==   |     왼쪽과 오른쪽이 같으면 참      |
|   !=   |   왼쪽과 오른쪽이 같지 않으면 참   |
|   >    |     왼쪽이 오른쪽보다 크면 참      |
|   <    |    왼쪽이 오른쪽보다 작으면 참     |
|   >=   | 왼쪽이 오른쪽보다 크거나 같으면 참 |
|   <=   | 왼쪽이 오른쪽보다 작거나 같으면 참 |

## 4.2 조건이 여러 개일 때: else if
- if-else : 조건이 하나이고 만족하는 경우와 아닌 경우
- if-else + else if : 조건이 여러개 일 때
```
if(조건 1) {
    실행문; // 조건 1을 만족할 때 실행할 명령문
} else if (조건 2) {
    실행문; // 조건 2를 만족할 때 실행할 명령문
} else if (조건 3) {
    실행문; // 조건 3을 만족할 때 실행할 명령문
} else {
    실행문; // 조건을 모두 만족하지 않을 때 실행할 명령문
}
```
- else if 블록은 조건 개수에 따라 여러번 사용할 수 있음
- 하지만 if문 없이 else if만 사용할 수는 없음
- 마지막은 모든 조건이 만족하지 않는 경우인 else 블록을 사용

- 예시 : 90점 이상 A학점, 80점 이상 90점 미만 B학점, 70점 이상 80점 미만 C학점, 그 외는 D학점
![!\[alt text\](image.png)](<학점 출력 코드의 순서도.png>)
- java는 조건을 `80 <= score < 90` 과 같이 적을 수 없고 나눠서 적은 후 `&&`라는 논리연산자로 작성하여 모두 만족하는 경우의 조건을 적을 수 있음
```java
public class Main {
    public static void main(String[] args) {
        int score = 80;
        if (score >= 90){
            System.out.println("A학점입니다.");
        } else if (score < 90 && score>=80 ){
            System.out.println("B학점입니다.");
        } else if (score < 80 && score>=70 ){
            System.out.println("C학점입니다.");
        } else {
            System.out.println("D학점입니다.");
        }
    }
}
```
- 실행 결과
```
B학점입니다.
```

### 4.2.1 논리 연산자
| 연산자 |                      설명                       |
| :----: | :---------------------------------------------: |
|   &&   |          왼쪽과 오른쪽 모두 참이면 참           |
|  \|\|  |          왼쪽과 오른쪽 모두 참이면 참           |
|   !    | 조건을 만족하면 거짓, 조건을 만족하지 않으면 참 |
