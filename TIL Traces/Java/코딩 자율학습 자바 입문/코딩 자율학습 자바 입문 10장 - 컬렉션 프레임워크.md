# 10장 컬렉션 프레임워크
## 10.1 컬렉션 프레임워크 개요
- 자료 구조 (data structure) : 데이터(값)을 저장하고 관리하는 방법
  - 자바의 기본 자료구조 예시
    - 배열 (Array) : 같은 자료형의 데이터를 연속적으로 저장하는 구조
      - 배열도 객체
      - 자바에서 모든 객체는 힙에 저장되고 참조로 관리됨
      - 배열을 생성하면 힙에 배열 요소를 저장하는 메모리 공간이 할당되고 스택에 생성된 참조 변수에 배열 객체의 주소가 저장됨
        - 스택의 참조변수에 있는 객체의 주소를 통해 힙 안의 값을 접근함
        - 이러한 참조를 통한 메모리 관리 방식으로 인해 배열을 객체로 취급함
      - 배열은 한번 생성하면 크기가 고정되고 나중에 데이터를 추가하기 어려움   
        => 데이터를 더 효율적으로 조작하고 관리하기 위해 자바에서 **컬렉션**을 제공함

    - 컬렉션 : 데이터를 그룹으로 묶어 하나의 객체로 관리할 수 있게 하는 자료 구조
      - 객체의 일종으로 객체를 모아놓은 데이터 집합
      - 컬렉션의 종류 : 리스트, 집합, 맵, 큐, 스택 등

- 배열과 컬렉션의 차이
  - 배열 
    - 생성할 때 크기를 지정하면 크기를 변경할 수 없고 연속 할당됨
    - 배열이 가득 찼을 때 새로운 데이터를 저장하려면 더 큰 크기의 배열을 새로 생성하고 기존 데이터를 복사해야함
    - 배열을 생성할 때 자료형을 지정되며 같은 자료형의 데이터로 구성됨
    - 인덱스를 통해 접근할 수 있지만 다른 기능은 거의 제공하지 않음
      - 데이터의 추가, 삭제, 검색, 정렬 등 직접 구현해야함
  - 컬렉션
    - 동적 크기를 가짐
    - 필요에 따라 크기를 자동으로 조절
    - 데이터의 추가와 삭제도 쉬움
    - 다양한 자료형을 지원하며 여러 타입의 객체를 담을 수 있음
    - 데이터의 추가, 삭제, 검색, 정렬 등 다양한 기능의 메서드를 제공
    - 다양한 자료구조와 알고리즘이 구현돼 있어 사용자가 필요에 따라 선택해서 쉽게 사용할 수 있음

- 컬렉션 프레임워크 : 컬렉션을 효과적으로 사용하고 관리할 수 있도록 설계된 인터페이스와 클래스의 집합
  - 컬렉션 : 데이터의 집합
  - 컬렉션 프레임워크 : 컬렉션을 다루기 위해 설계한 코드 구조이자 도구
    - 다양한 컬렉션을 손쉽게 생성하고 수정 및 관리할 수 있음
    - 자료 구조의 구현을 신경 쓰지 않고 표준화된 구조를 이용해 일관된 방식으로 작업할 수 있음

### 10.1.2 컬렉션 프레임워크의 구조
- 컬렉션 프레임워크 : 다양한 구조와 알고리즘을 표준화해 제공
  - 리스트, 집합, 맵, 큐, 스택 등 자료구조를 표준화한 인터페이스들로 구성됨

1. Collection 인터페이스
- 컬렉션 프레임워크의 최상위 인터페이스로 각 컬렉션의 공통된 동작을 정의
- Collection 인터페이스를 직접 구현한 클래스는 없지만 자식 인터페이스들이 이를 상속해 기능을 확장
![alt text](<컬렉션 프레임워크의 구조.png>)

2. List 인터페이스
- 삽입된 순서대로 요소를 저장하는 리스트 컬렉션을 정의하는 인터페이스
- 중복 요소를 허용하며 각 요소에는 인덱스로 접근할 수 있음
- 주요 구현 클래스
  - ArrayList : 배열로 구현된 클래스
  - LinkedList : 이중 연결 리스트로 구현된 클래스
  - Vetor : ArrayList와 유사한 리스트이나 현재는 잘 사용하지 않음
  - Stack : Vector 클래스를 상속받아 구현된 클래스
    - 나중에 들어온 요소가 먼저 처리되는 LIFO(Last-In First-Out, 후입선출) 방식으로 요소를 관리함

3. Set 인터페이스
- 순서를 보장하지 않으며 중복 요소를 허용하지 않는 집합 컬렉션을 정의하는 인터페이스
- 수학의 집합 개념을 생각하면 이해하기 수월
- 주요 구현 클래스
  - HashSet : 해시 테이블 구조로 구현된 집합
  - LinkedHashSet : HashSet의 변형 집합, 삽입된 순서를 유지
  - TreeSet : 이진 트리 구조로 구현된 집합, 요소가 정렬된 상태로 저장

4. Map 인터페이스
- 키와 값을 한 쌍으로 저장하는 맵 컬렉션을 정의하는 인터페이스
- 키는 중복을 허용하지 않음
- 주요 구현 클래스
  - HashMap : 해시 테이블을 기반으로 구현된 클래스
    - 키와 값의 순서가 보장되지 않음
  - LinkedHashMap : HashMap의 변형으로 삽입된 순서를 유지함
  - TreeMap : 이진 트리 구조를 사용한 맵으로 키를 기준으로 정렬됨

5. Queue 인터페이스
- 먼저 삽입된 요소가 먼저 처리되는 FIFO(First-In First-Out, 선입선출) 방식으로 요소를 관리하는 큐 컬렉션의 인터페이스
- 큐의 뒤(rear)에서 요소를 삽입하고 큐의 앞(front)에서 요소를 삭제
- 중복 요소 허용
- 주요 구현 클래스
  - ProrityQueue : 우선순위에 따라 요소가 정렬돼 처리되는 큐
  - ArrayDeque : Queue 인터페이스를 상속받은 Deque 인터페이스를 구현한 클래스
    - 큐와 스택으로 모두 사용할 수 있음
  - LinkedList : Queue 인터페이스를 구현해 FIFO 방식으로 요소를 관리할 수도 있음

6. Deque 인터페이스
- Deque(덱)은 Double-Ended Queue의 약자로 양방향 큐를 정의하는 인터페이스
- 큐의 양쪽 끝에서 요소를 추가하고 삭제할 수 있는 구조
- 스택과 큐의 기능을 둘 다 지원해 LIFO, FIFO 2가지 방식으로 데이터를 처리할 수 있음
  - Stack : 자바에서 제공하는 전통적인 스택 클래스
    - Vector 클래스를 상속받아 구현되며 LIFO 방식을 따름
  - ArrayDequeue : 더 현대적인 스택 클래스로, 스택과 큐의 모든 기능을 지원함

### 10.1.3 래퍼 클래스
- 래퍼 클래스(Wrapper class) : 기본형의 값을 객체로 변환해주는 클래스
- 자바의 자료형
  - 기본형 : 정수형, 실수형, 문자형, 논리형의 값을 저장
  - 참조형 : 객체의 위치를 나타내는 주소를 저장
- **컬렉션은 객체만 저장할 수 있으며 기본 자료형의 값을 사용하려면 객체로 변환해주는 래퍼 클래스가 필요함**
- 기본형마다 대응되는 래퍼 클래스가 존재하며 기본형에 해당하는 값을 래퍼 클래스에 전달하면 해당 값을 가지는 객체로 변환됨 => java.lang 패키지에 포함됨

<br>

- 래퍼 클래스의 종류

| 기본형  | 래퍼 클래스 |
| :-----: | :---------: |
|  byte   |    Byte     |
|  char   |  Character  |
|   int   |   Integer   |
|  float  |    Float    |
| double  |   Double    |
| boolean |   Boolean   |
|  long   |    Long     |
|  short  |    Short    |

- 박싱 : 기본형 값을 래퍼 클래스로 감싸 객체로 변환하는 과정
- 오토 박싱 : 자바 5 이후부터는 래퍼 클래스로 명시적으로 감싸지 않아도 값에 대응되는 래퍼 클래스 객체로 변환됨
```JAVA
package ch10;

public class Main {
    public static void main(String[] args){
        int a = 5;
        // 명시적 박싱 => 오류 남, 자바 9부터는 Deprecated(사용 중지 권고됨)
        Integer aObj = new Integer(a);

        // 오토 박싱
        int b = 10;
        Integer bObj = b;
    }
}
```

- 언박싱 : 객체를 기본형으로 변환하는 것
- 오토언박싱 : 자바 5 이후부터는 언박싱이 자동 변환됨
```JAVA
package ch10;

public class Main {
    public static void main(String[] args){    
        // 명시적 언박싱
        Integer numObj = new Integer(10);
        int num = numObj.intValue();
        
        // 오토 언박싱
        Integer numObj2 = 10;
        int num2 = numObj2;
    }
}

```

### 10.1.4 제네릭
- Object : 모든 클래스의 최상위 부모 클래스
  - 클래스가 명시적으로 다른 클래스를 상속하지 않으면 암묵적으로 Object 클래스를 상속하게 됨
  - 클래스나 메서드를 정의할 때 자료형을 미리 정하지 않고 직접 지정하고 싶은 경우 과거엔 Object형을 사용함
  - Object형으로 변수를 선언한 경우 어떤 자료형의 객체든 참조할 수 있음
  - 다만 Object형으로 선언된 변수를 사용할 때는 **명시적 형변환**을 해야함
    - 만약 잘못된 자료형으로 변환하면 런타임 오류가 발생

  - 예시 
    ```JAVA
      public class ObjectType {
              private Object content;

              public void setContent(Object content) {
                  this.content = content;
              }

              public Object getContent() {
                  return content;

          }

          public static void main(String[] args) {
              ObjectType box = new ObjectType(); // 내부 클래스 인스턴스 생성
              box.setContent("Hello, World!");
              Integer number = (Integer) box.getContent(); // 잘못된 타입 캐스팅
              System.out.println(number);
          }
      }

    ```
  - 실행 결과
    ```JAVA
    Exception in thread "main" java.lang.ClassCastException: class java.lang.String cannot be cast to class java.lang.Integer
    ```
    - box의 형태를 Integer 형으로 변환했지만 content 필드에 저장된 값은 String 형으로 형변환할 수 없어 `ClassCastException` 예외가 발생함 => 타입 안정성이 보장되지 않음

<br>

- 타입 안정성 : 프로그래밍 언어에서 데이터의 자료형이 예상하지 못한 방식으로 변환되거나 잘못된 자료형의 데이터가 사용되는 것을 방지하는 성질을 의미함

- 제네릭 : 타입 안정성을 보장하고 코드 재사용성을 높이기 위해 자바에 도입된 기능
  - 타입 매개변수를 사용함
    - 타입 매개변수 : 인터페이스, 클래스 정의할 때 자료형을 지정하지 않고 나중에 지정할 수 있게 하는 변수
      - 나중에 사용할 때 해당 객체에 저장할 수 있는 값의 자료형을 넣음
      - 마치 메서드의 매개변수처럼 자료형을 다룬다고 하여 **타입 매개변수**라고 함
  - 형식 
    ```JAVA
    class 클래스명<타입_매개변수> {} // 클래스
    public <타입_매개변수> 반환형 메서드명(타입_매개변수 매개변수); // 메서드
    ```
  - 타입 매개변수는 주로 알파벳 한글자로 표현하는 것이 암묵적인 규칙으로 다른 문자를 사용해도 됨
    - 많이 사용하는 타입 매개변수
      - <T>(Type): 클래스나 메서드에서 가장 많이 사용하는 형태의 타입 매개변수
        - Integer, String, Double 등 다양한 참조형으로 대체할 수 있음
      - <E>(Element): 주로 List나 Set의 구현 클래스에서 요소를 나타낼 때 사용함
        - E는 각 요소의 자료형을 의미함
      - <K,V>(Key, Value): Map처럼 키-값 쌍을 다루는 자료구조에 사용함
        - K는 키의 자료형, V는 값의 자료형을 나타냄
      - <N>(Number): 주로 숫자형을 다루는 클래스나 메서드에서 사용
  - 실제 객체를 생성할 때는 자료형을 지정함
    - 형식

        ```JAVA
        클래스명<자료형> 변수 = new 클래스명<자료형>();
        클래스명<자료형> 변수 = new 클래스명<>(;)
        ```

    - 생성자를 호출하는 부분에서 자료형을 유추할 수 있으면 두번째 형식처럼 다이아몬드 연산자(<>)를 사용해 자료형을 생략할 수 있음

- 제네릭을 사용한 Box 클래스 예제
  ```JAVA
    package ch10;

    public class Generic<T> {
            private T content;

            public void setContent(T content){
                this.content = content;
            }

            public T getContent(){
                return content;
            }
            
        public static void main(String[] args) {
            Generic<String> box = new Generic<>() ; // String형의 Box 객체 생성
            box.setContent("Hello, World!"); // 문자열 저장
            String content = box.getContent(); // 형변환 불필요
            System.out.println(content);
        }
    }
  ```

  - 실행 결과
    ```JAVA
    Hello, World!

    ```
    - 제너릭을 사용하면 하나의 코드를 여러 자료형에서 재사용할 수 있음
    - 제너릭을 사용하면 저장하는 값의 자료형이 고정됨 => 다른 참조형의 객체를 저장하려고 하면 컴파일 오류가 발생하여 `타입 안전성`을 보장함
    - 형변환을 하지 않아도 돼서 코드가 간결해짐

## 10.2 컬렉션 프레임워크의 주요 인터페이스
- List, Set, Map

### 10.2.1 List 인터페이스
- List 인터페이스 : 기본 자료 구조인 리스트를 정의한 인터페이스
- List 인터페이스를 구현한 클래스의 특징
1. 요소들이 삽입된 순서를 유지함
  - 첫번째로 삽입된 요소는 첫번째 인덱스에 두번째로 삽입된 요소는 두번째 인덱스에 저장
2. 중복을 허용
  - 같은 값의 요소를 여러번 추가할 수 있음
3. 각 요소를 가리키는 인덱스가 있고 이를 통해 요소를 접근할 수 있음
  - 인덱스는 0부터 시작함
4. 크기가 변경될 수 있음
  - 요소를 추가하거나 삭제하면 크기가 자동으로 조정됨

<br>

- List 인터페이스가 제공하는 메서드

  |      메서드       |                                     설명                                     |
  | :---------------: | :--------------------------------------------------------------------------: |
  |     add(요소)     |                          리스트의 끝에 요소를 추가                           |
  | add(인덱스, 요소) | 지정된 인덱스에 요소를 삽입함, 해당 위치 이후의 요소들은 한 칸씩 뒤로 미려남 |
  |    get(인덱스)    |                       지정된 인덱스에 있는 요소를 반환                       |
  | set(인덱스, 요소) |                  지정된 인덱스의 요소를 새로운 요소로 바꿈                   |
  |  remove(인덱스)   |                      지정된 인덱스에 있는 요소를 삭제함                      |
  |      clear()      |                         리스트의 모든 요소를 삭제함                          |
  |      size()       |                         리스트의 요소 개수를 반환함                          |
  |     isEmpty()     |                         리스트가 비어 있는지 확인함                          |
  |  contains(요소)   |                  지정한 요소가 리스트에 포함돼 있는지 확인                   |

#### (1) ArrayList 클래스
- List 인터페이스의 대표적인 구현 클래스로 배열과 마찬가지로 **연속된 메모리 공간**에 데이터를 저장함
- 따로 크기를 명시하지 않으면 **기본 용량인 10**을 할당
- ArrayList 배열에 요소를 추가하다 용량이 부족하면 기존 배열의 1.5~2배 더 큰 새로운 배열을 생성
  - 기존 배열의 요소들을 새로운 배열로 복사
  - 복사 후 기존 배열에 대한 참조는 해제되고 메모리에서도 삭제됨
    - JVM의 가비지 컬렉터 (GC, Garbage Collector)에서 담당
- 일반 배열은 크기가 고정이라 `정적 배열`, ArrayList는 크기가 가변이어서 `동적 배열`이라고도 함
- ArrayList는 java.util 패키지에 포함되어있으며 이미 구현된 클래스라 바로 객체를 생성해 사용할 수 있음

- ArrayList 객체 생성 방법
  ```JAVA
  1. ArrayList<자료형> 변수 = new ArrayList<>([용량]);
  2. List<자료형> 변수 = new ArrayList<>([용량]);
  3. ArrayList<자료형> 변수 = new ArrayList<>(다른_컬렉션_변수);
  ```
  1. ArrayList 클래스로 객체를 생성하는 방법
    - ArrayList 클래스의 고유 메서드가 필요할 때 사용하는 형식
    - 자료형에는 해당 객체에 저장할 값의 자료형을 지정 (예 : String)
    - 용량을 지정하지 않으면 기본 용량인 10으로 지정됨
  2. List 인터페이스로 객체를 생성하는 방법
    - List의 여러 구현 클래스를 사용할 수 있음
    - 대신 ArrayList 클래스의 고유한 메서드를 사용할 수 없음
  3. 이미 존재하는 다른 컬렉션으로 객체를 생성하는 방법
     - 이미 존재하는 컬렉션 데이터를 기반으로 새로운 컬렉션을 생성할 수 있음
     - 예: originalList에 저장된 데이터로 newList 객체를 생성해 초기화할 수 있음
        ```JAVA
        ArrayList<String> originalList = new ArrayList<>();
        ArrayList<String> newList = new ArrayList<>(originalList);
        ```

- ArrayList 활용 예시
  ```JAVA
  package ch10;

  import java.util.ArrayList;

  public class ArrayListExample {
      public static void main(String[] args){
          ArrayList<String> list = new ArrayList<>();

          list.add("Apple");
          list.add("Banana");
          list.add("Cherry");

          System.out.println(list.get(1));
          list.set(1, "Durian");
          System.out.println(list.get(1));
          list.remove(0);

          System.out.printf("리스트 크기: %d%n", list.size());
          System.out.printf("리스트가 비었는가? %b%n", list.isEmpty());
          System.out.println(list);

      }
  }

  ```

#### (2) LinkedList 클래스
- java.util 패키지에 포함된 컬렉션 클래스 중 하나
- ArrayList와는 달리 LinkedList는 데이터가 연속적으로 저장되지 않음
  - 대신 앞뒤 요소에 참조를 가지고 연결돼 있음 => 이중 연결 리스트(doubly linked list)라고 함
  ![alt text](<LinkedList 구조.png>)
- 이런 구조로 인해 요소가 참조하는 주소만 변경하면 되기 때문에 데이터를 삽입하거나 삭제하기가 쉬움
- 대신 인덱스로 특정 위치에 접근하려면 순차적으로 탐색해야해서 ArrayList보다 느림
- LinkedList 클래스도 List 인터페이스를 구현하여 ArrayList와 기능이 비슷한 메서드들을 제공함
- Deque 인터페이스도 구현하여 큐의 기능도 추가로 제공

<br>

- LinkedList 클래스의 고유 메서드 

  |     메서드     |                                              설명                                              |
  | :------------: | :--------------------------------------------------------------------------------------------: |
  | addFirst(요소) |                             리스트의 첫 번째 위치에 요소를 추가함                              |
  | addLast(요소)  |                               리스트의 마지막 위치에 요소를 추가                               |
  |   getFirst()   |                                  리스트의 첫번째 요소를 반환                                   |
  |   push(요소)   |                                리스트의 앞 부분에 요소를 추가함                                |
  |     pop()      |                              리스트의 첫번째 요소를 삭제하고 반환                              |
  |  removeLast()  |                              리스트의 마지막 요소를 삭제하고 반환                              |
  |  offer(요소)   |      LinkedList가 큐로 동작할 때 사용, 큐의 맨 뒤에 요소를 삽입하고 성공하면 true를 반환       |
  |     poll()     | LinkedList가 큐로 동작할 때 사용, 큐의 맨 앞 요소를 삭제하고 반환, 큐가 비어있으면 null을 반환 |
  |      peek      |                    LinkedList가 큐로 동작할 때 사용, 큐의 맨 앞 요소를 반환                    |

<br>

- LinkedList 클래스 객체를 생성하는 방법
  ```JAVA
  LinkedList<자료형> 변수 = new LinkedList<>();
  List<자료형> 변수 = new LinkedList<>();
  LinkedList<자료형> 변수 = new LinkedList<>(다른 컬렉션 변수);
  ```
- LinkedList 활용 예시
  ```JAVA

  package ch10;

  import java.util.LinkedList;

  public class LinkedListExample {
      public static void main(String[] args){
          LinkedList<String> list = new LinkedList<>();
          list.addFirst("Apple"); // 맨 앞 Apple 삽입
          list.addLast("Banana"); // 맨 뒤 Banana 삽입
          list.push("Cherry"); // 맨 앞 Cherry 삽입
          System.out.println("1번 출력 - 리스트 상태: " + list); // 1번 출력 - 리스트
          System.out.println("2번 출력 - 첫번째 요소: " + list.getFirst()); // 2번 출력 - 첫번째 요소 출력
          list.pop(); // 맨 앞 요소 삭제 후 반환
          System.out.println("3번 출력 - 리스트 상태: " + list); //3번 출력 - 리스트
          list.removeLast(); // 맨 뒤 요소 삭제 후 반환
          System.out.println("4번 출력 - 리스트 상태: " + list); //4번 출력 - 리스트
          list.addLast("Durian"); // 맨 뒤 요소 추가
          System.out.println("5번 출력 - 리스트 상태: " + list); //5번 출력 - 리스트
          list.pop(); // 맨 앞 요소 삭제 후 반환
          System.out.println("6번 출력 - 리스트 상태: " + list); //6번 출력 - 리스트
          System.out.println("7번 출력 - 첫번째 요소: " + list.getFirst()); //7번 출력 - 첫번째 요소 출력
          System.out.println("8번 출력 - 최종 리스트: " + list); //8번 출력 - 리스트

      }
  }

  ```

    ```JAVA
    5번 출력 - 리스트 상태: [Apple, Durian]
    ```

### 10.2.2 Set 인터페이스
- Set 인터페이스는 집합 자료구조를 정의한 인터페이스
- 중복 요소를 허용하지 않으며 요소들의 순서가 정해져 있지 않음

<br>

- Set 인터페이스 메서드

  |     메서드     |                                 설명                                 |
  | :------------: | :------------------------------------------------------------------: |
  |   add(요소)    | 집합에 요소를 추가함, 해당 요소가 집합에 이미 존재하면 추가되지 않음 |
  |  remove(요소)  |                     지정된 요소를 집합에서 삭제                      |
  | contains(요소) |                집합에 해당 요소가 있는지 여부를 반환                 |
  |   size(요소)   |                   집합에 포함된 요소의 개수를 반환                   |
  |   isEmpty()    |                    집합이 비어 있는지 여부를 반환                    |
  |   iterator()   |             집합 요소들을 순회할 수 있는 반복자를 반환함             |

  - 반복자(Iterator)는 컬렉션에 저장된 요소들에 순차적으로 접근하는데 사용되는 객체
    - Iterator 인터페이스에 정의돼 있으며 반복 처리를 위한 다양한 메서드를 제공함
    - 예 : iterator() 
      - 반복자를 생성하고 반환하며 생성한 반복자들을 사용해 컬렉션의 요소들을 순회할 수 있음

#### (1) HashSet
- Set 인터페이스의 대표적인 구현 클래스
- 요소들을 해시 테이블(hash table, 키-값으로 된 데이터를 저장하는 자료구조)에 저장
- 빠른 검색, 추가, 삭제 기능을 제공하며 요소의 순서는 유지되지 않음
- 배열이나 리스트에서 중복 요소를 삭제할 때 유용
- 특정 요소가 존재하는지를 빠르게 확인해야 할 때도 사용할 수 있음

- HashSet 클래스 객체 생성 방법
  ```JAVA
  HashSet<자료형> 변수 = new HashSet<>([용량, 부하율]);
  Set<자료형> 변수 = new HashSet<>([용량, 부하율]);
  HashSet<자료형> 변수 = new HashSet<>(다른 컬렉션 변수);
  ```
  - ArrayList와 마찬가지로 용량을 지정할 수 있고 지정하지 않으면 기본 용량인 16으로 생성됨
  - HashSet은 부하율을 지정할 수 있음
    - 부하율(load factor) : 해시 테이블의 크기 대비 저장된 요소의 비율
      - 기본 부하율 : 0.75 => 해시 테이블이 75% 차게 되면 크기를 두배로 늘림

- HashSet 사용 예시
  ```JAVA
  package ch10;

  import java.util.HashSet;
  import java.util.Iterator;

  public class HashSetExample {
      public static void main(String[] args){
          HashSet<String> fruits = new HashSet<>(); // 객체 생성

          fruits.add("Apple");
          fruits.add("Banana");
          fruits.add("Cherry");
          System.out.println("집합 상태: " + fruits);
          fruits.add("Apple"); // 중복을 허용하지 않아 추가되지 않음
          System.out.println("집합 상태: " + fruits);
          System.out.println("집합 크기: " + fruits.size());

          System.out.println("Banana가 있는가? " + fruits.contains("Banana")); // 요소 여부 확인
          System.out.println("Banana가 삭제됐는가? " + fruits.remove("Banana")); // 요소 삭제 및 확인
          System.out.println("Banana가 있는가? " + fruits.contains("Banana")); // 요소 여부 확인
          System.out.println("집합 상태: " + fruits);
          System.out.println("집합이 비어 있는가? " + fruits.isEmpty());

          System.out.println("집합 요소: ");
          // Iterator 인터페이스를 통해 객체 생성 후 사용법
          Iterator<String> iterator = fruits.iterator();
          // hasNext() : 다음 요소가 있는지 확인하고 있으면 true
          while (iterator.hasNext()){
              // next() : 다음 요소를 반환
              System.out.println(iterator.next());
          }

          fruits.clear(); // 요소 전체 삭제
          System.out.println("최종 집합 크기: " + fruits.size());
          System.out.println("집합이 비어 있는가? " + fruits.isEmpty());

      }
  }

  ```

  - 실행 결과
    ```JAVA
    집합 상태: [Apple, Cherry, Banana]
    집합 상태: [Apple, Cherry, Banana]
    집합 크기: 3
    Banana가 있는가? true
    Banana가 삭제됐는가? true
    Banana가 있는가? false
    집합 상태: [Apple, Cherry]
    집합이 비어 있는가? false
    집합 요소: 
    Apple
    Cherry
    최종 집합 크기: 0
    집합이 비어 있는가? true
    ```

### 10.2.3 Map 인터페이스 
- Map은 키와 값의 한 쌍으로 이루어진 자료구조를 정의한 인터페이스 
- Map 인터페이스는 하나의 키에 하나의 값을 매핑해 항목(entry)로 저장함
  - 키는 고유해야하지만 값은 중복될 수 있음
  - 같은 키로 값을 저장하면 기존 값을 덮어씀

- Map 인터페이스에서 사용하는 메서드 

  |      메서드       |                                        설명                                        |
  | :---------------: | :--------------------------------------------------------------------------------: |
  |    put(키, 값)    | 저장된 키와 값을 맵에 추가함, 키가 이미 존재하는 경우 기존 값을 새로운 값으로 대체 |
  |      get(키)      |           저장된 키에 매핑된 값을 반환함, 키가 맵에 없으면 null을 반환함           |
  |    remove(키)     |                       지정된 키에 매핑된 항목을 맵에서 삭제                        |
  |  containsKey(키)  |                          지정된 키가 맵에 존재하는지 확인                          |
  | contiansValue(값) |                지정된 값이 맵에 하나 이상의 키로 매핑돼 있는지 확인                |
  |     keySet()      |                        맵에 포함된 모든 키를 Set형으로 반환                        |
  |     values()      |                    맵에 포함된 모든 값을 Collection형으로 반환                     |
  |    entrySet()     |                       맵에 포함된 모든 항목을 Set형으로 반환                       |

#### (1) HashMap 클래스
- HashMap 클래스는 가장 널리 사용되는 Map 인터페이스의 구현 클래스 
- 키와 값을 한 쌍으로 저장하는 해시 테이블 기반 구조 
- HashMap 클래스는 키를 기반으로 한 데이터 검색, 삽입, 삭제가 매우 빠름
- 대량의 데이터를 다룰 때 효율적
- 키와 값의 순서를 보장하지 않아 데이터를 저장한 순서와 조회할 때 순서가 다를 수 있음

<br>

- 객체 생성 방법
  ```JAVA
  HashMap<자료형, 자료형> map = new HashMap<>([용량, 부하율]);
  Map<자료형, 자료형> map = new HashMap<String, Integer>([용량, 부하율]);
  ```
  - 키와 값을 한 쌍으로 저장하여 자료형이 2개이며 자료형이 같을 필요는 없음
  - HashSet과 마찬가지로 용량을 지정하거나 지정하지 않을 수 있고 지정하지 않으면 기본 용량 16으로 생성됨
  - HashMap의 기본 부하율도 0.75로 설정되어있음

- HashMap 활용 예시
    ```JAVA
    package ch10;

    import java.util.Collection;
    import java.util.HashMap;
    import java.util.Set;

    public class HashMapExample {
        public static void main(String[] args){
            HashMap<String, Integer> map = new HashMap<>();

            map.put("Apple", 10);
            map.put("Banana", 15);
            map.put("Cherry", 20);
            map.put("Durian", 25);
            System.out.println("Apple의 수량: " + map.get("Apple"));

            map.remove("Banana");
            System.out.println("맵 상태: " + map);
            System.out.println("Cherry가 있는가? " + map.containsKey("Cherry"));
            System.out.println("값이 10인 항목이 있는가? " + map.containsValue(10));

            // keySet()이 반환하는 값는 Set 형
            Set<String> keys = map.keySet();
            System.out.println("모든 키: " + keys);

            // values() 메서드가 반환하는 값은 Collection 형
            Collection<Integer> values = map.values();
            System.out.println("모든 값: " + values);
        }
    }
    ```

  - 실행 결과
    ```JAVA
    Apple의 수량: 10
    맵 상태: {Apple=10, Cherry=20, Durian=25}
    Cherry가 있는가? true
    값이 10인 항목이 있는가? true
    모든 키: [Apple, Cherry, Durian]
    모든 값: [10, 20, 25]
    ```

## 향상된 for문
- 향상된 for문(enhanced for loop)은 자바5에서 도입된 반복문의 한 형태로, 배열이라 컬렉션을 더 간단하고 가독성 있게 순회할 수 있음

```JAVA
for (자료형 변수 : 배열명/컬렉션명){
  // 실행문
}
```
- 초기화 변수나 증감식 없이 모든 요소를 자동으로 순회
- 배열이나 컬렉션의 요소를 변수로 하나씩 접근해 특정 작업을 할 때 유용함

## 셀프 체크
  ```JAVA
  package ch10;

  import java.util.ArrayList;
  import java.util.HashMap;
  import java.util.HashSet;

  public class SelfCheck {
      public static void main(String[] args){
          // 1. ArrayList
          ArrayList<String> students = new ArrayList<>();
          students.add("홍길동");
          students.add("김길벗");
          students.add("이코천");
          students.add("홍길동");

          System.out.println("1. ArrayList 출력: " + students);
          System.out.println("학생 명단 : ");
          for (String student:students) { // 향상된 for문으로 명단 출력
              System.out.println(student);
          }

          // 2. HashSet
          // HashSet을 ArrayList students로 초기화
          HashSet<String> students2 = new HashSet<>(students);
          students2.add("강남순");

          System.out.println("2. HashSet 출력: " + students2);
          System.out.println("학생 명단(중복 삭제) : ");
          for (String student:students2){
              System.out.println(student);
          }
          
          // HashSet으로 HashMap 만들기
          HashMap<String , Integer > studentsScore = new HashMap<>();
          studentsScore.put("홍길동", 85);
          studentsScore.put("김길벗", 92);
          studentsScore.put("이코천", 78);
          studentsScore.put("강남순", 90);
          System.out.println("3. HashMap 출력: " + studentsScore);
          System.out.println("4. 홍길동 확인: " + studentsScore.get("홍길동"));
          System.out.println("학생 명단과 점수 : ");
          for (String key: studentsScore.keySet()){
              System.out.println(key + "의 점수" + studentsScore.get(key) + "점");
          }
      }
  }

  ```
  - 실행 결과
    ```JAVA

    김길벗
    이코천
    홍길동

    김길벗
    3. HashMap 출력: {홍길동=85, 강남순=90, 이코천=78, 김길벗=92}
    4. 홍길동 확인: 85
    학생 명단과 점수 :
    ```
