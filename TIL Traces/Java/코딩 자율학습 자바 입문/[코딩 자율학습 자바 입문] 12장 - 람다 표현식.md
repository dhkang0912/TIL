# 12장 람다 표현식
- 함수형 프로그래밍(functional programming)은 프로그램을 수학적 함수의 조합으로 생각하는 프로그래밍 기법
  - 명확하고 이해하기 쉬운 표현식을 사용해 코드를 읽기 쉽고 유지 보수성이 좋음
  - 예 : 람다 표현식, 스트림 API
- 순수 함수 : 단일 기능으로 이루어진 함수 조합
  - 동일한 입력을 받으면 항상 동일한 결과를 반환하고 부수 효과를 일으키지 않음
    - 부수 효과 : 외부의 값을 변경함
  - 부수 효과를 일으키지 않기 때문에 코드가 안정적이고 결과가 예측 가능하며 멀티 스레드 환경에서도 안전하게 실행될 수 있음

## 12.1 람다 표현식 사용하기
- 람다 표현식 : 함수를 하나의 표현식으로 나타내는 방법
  - 람다식은 **익명 함수**로 작성함
    - 익명 함수 : 이름이 없는 함수로 함수를 따로 정의하지 않고 코드 자체를 변수에 할당해 변수처럼 사용함
  - 보통 해당 함수 프로그램에서 한번만 사용하고 다시 사용하지 않는 코드나 짧은 코드 블록을 작성할 때 사용함
  - 람다식으로 함수를 작성하면 코드가 간결해지고 코드의 가독성을 높일 수 있음
  - 형식
    ```JAVA
    ([자료형] 매개변수) -> {실행문;}
    ```
    - 소괄호에 함수에 전달되는 인자를 받는 매개변수를 넣음
    - 매개변수의 자료형은 생략할 수 있으며 매개변수가 하나일 때는 소괄호도 생략할 수 있음
    - ->는 화살표 연산자라고 하며 매개변수와 표현식을 구분하며 매개변수를 표현식에 전달하는 역할을 함
    - {}로 묶어 반환할 표현식을 넣으며 실행할 내용이 한문장이면 중괄호를 생략할 수 있음
    - 중괄호를 생략하면 return 키워드와 세미콜론도 생략하고 표현식만 작성해야함

- 예시
1. add 함수
```JAVA
int add(int a, int b){
    return a+b;
}
```

1. add 람다식
```JAVA
(int a, int b) -> a+b

// 또는

(a,b) -> a+b
```

3. isEven 함수
```JAVA
boolean isEven(int n){
    if(n%2 == 0)
        return true;
     else 
        return false;
}
```

4. isEven 람다식
```JAVA
(n) => {
    if (n%2 == 0)
        return true;
    else
        return false;
}
```

5. isEven 삼항 연산자
- 삼항 연산자
```JAVA
// 삼항 연산자 형식
(조건) ? A : B
```

- isEven 삼항 연산자
```JAVA
n -> n%2 == 0 ? true : false
```
    - 매개변수가 하나이므로 소괄호를 생략할 수 있음
    - 참 또는 거짓일 때 반환값만 남김

- 자바의 메서드와 함수형 프로그래밍의 차이
  - 자바에서 메서드는 변수를 할당할 수 없음
    - 자바에서 메서드는 클래스 안에 있어야 하고 객체를 통해 호출 가능함
    - 따라서 함수 자체를 변수에 저장하거나 다른 메서드의 인자로 넘기는 것이 불가능
  - 자바의 메서드는 클래스 안에 정의하고 객체를 생성한 후에 객체로 호출해서 사용  
    => 자바에서 클래스 없이 메서드를 함수처럼 사용하기 위해 만든 것이 람다식
  - 람다식으로 함수형 프로그래밍을 구현하기 위해 등장한 것이 `함수형 인터페이스`


## Note 메서드 참조
- 메서드 참조 : 람다식을 더 간결하게 표현하는 방법
  - 이미 존재하는 메서드를 참조해 람다식에서 사용하려 할 때 필요함
  - 메서드 참조는 :: 연산자를 사용하여 표현함

- 형식
```JAVA
객체명::메서드명 // 인스턴스 메서드 참조 시
클래스명 :: 메서드명 // 클래스 메서드 참조 시
클래스명::new // 생성자 참조 시
```
- 예 : 리스트의 모든 문자열을 대문자로 변환할 때 람다식을 사용하는 방법과 메서드 참조를 사용하는 방법을 비교
```JAVA
// 람다 표현식을 사용한 방법
words.replaceAll(s->s.toUpperCase());
// 메서드 참조를 사용한 방법
words.replaceAll(String::toUpperCase);
```

## 12.2 함수형 인터페이스 사용하기
- 람다식을 변수에 할당하려면 변수의 자료형이 필요함 => 함수형 인터페이스가 자료형 역할을 수행
  - 메서드를 클래스 내부가 아닌 다른 곳에서 사용하기 위해서는 객체를 생성하고 호출해야함
  - 클래스 없이 메서드를 함수처럼 사용하기 위해 람다식을 사용하며 람다식으로만 함수형 프로그래밍을 구현하기 위해 인터페이스를 사용

- 함수형 인터페이스 : 한 개의 추상 메서드만 가지는 인터페이스
  - 인터페이스는 직접 객체를 생성할 수 없지만 `함수형 인터페이스`는 람다식을 `함수형 인터페이스 타입의 변수에 할당해 객체처럼 사용`할 수 있음
  - 객체를 변수로 참조하듯이 `람다식을 변수로 참조`할 수 있기 때문에 객체를 생성하지 않아도 변수를 통해 람다식에 접근해 값을 전달하고 값을 반환 받을 수 있음
- 형식
    ```JAVA
    @FunctionalInterface
    interface 인터페이스명 {
        추상_메서드();
    }
    ```
    - 함수형 인터페이스를 나타내는 @FunctionalInterface 애너테이션을 추가할 수 있음

- 객체 생성 방식과 람다식을 사용한 방식의 차이 예시 : 짝수 홀수 판단
- 객체 생성 방식
1. 입력한 값이 짝수인지 확인하는 isEven() 메서드를 추상 메서드로 가진 Check 인터페이스를 정의
```JAVA
interface Check{ // 인터페이스 정의
    abstract boolean isEven(int n); // 추상 메서드 선언

}
```

2. Check 인터페이스를 구현한 EvenCheck 클래스를 다음과 같이 작성
```JAVA
interface Check{ // 인터페이스 정의
    abstract boolean isEven(int n); // 추상 메서드 선언

}

class EvenCheck implements Check{ // Check 인터페이스의 구현 클래스
    public boolean isEven(int n){
        if(n%2 == 0)
            return true;
        else
            return false;
    }
}
```

3. TraditionalExample 클래스에 main() 메서드를 생성함, EvenCheck 클래스로 객체를 생성하고 생성한 객체로 isEven() 메서드를 호출
```JAVA
public class TraditionalExample {
    public static void main(String[] args){
        EvenCheck even = new EvenCheck(); // 객체 생성
        System.out.println(even.isEven(15)); // 객체로 isEven() 메서드 호출
    }
}
```

- 람다식 사용 방식
1. Check 인터페이스에서 구현 클래스인 EvenCheck 클래스를 주석 처리 
```JAVA
@FunctionalInterface
interface Check{ // 인터페이스 정의
    abstract boolean isEven(int n); // 추상 메서드 선언
}
```

1. LamdaExample 클래스에 main() 메서드를 생성한 후 입력 값이 짝수인지 확인하는 isEven() 메서드를 람다식으로 수정
작성한 람다식을 참조할 수 있게 Check 인터페이스형으로 선언한 even 변수에 할당

```JAVA
public class LamdaExample {
    public static void main(String[] args){
        // 추상 메서드를 람다식으로 구현한 후 Check 인터페이스형 참조 변수에 할당
        Check even = n -> n%2 == 0 ? true : false;
        System.out.println(even.isEven(15)); // 변수로 isEven() 메서드 접근
    }
}
```

## 12.3 자바에서 제공하는 함수형 인터페이스 
### 12.3.1 Predicate 인터페이스 
- Predicate 인터페이스 : 주어진 값을 평가해 boolean 값 (true or false)을 반환하는 조건식을 정의할 때 사용함
  - 주로 필터링, 조건 검증 등에서 사용하며, java.util.function 패키지에 포함돼 있음

```JAVA
public interface Predicate<T>{
    boolean test(T t);
}
```

- Predicate 인터페이스를 통해 값이 짝수인지 판별하는 코드 
    ```JAVA
    import java.util.function.Predicate;

    public class PredicateExample {
        public static void main(String[] args){
            Predicate<Integer> isEven = (n) -> n%2 == 0 ;
            System.out.println(isEven.test(1));
            System.out.println(isEven.test(2));
        }
    }
    ```

- 실행 결과
    ```JAVA
    false
    true
    ```

- Predicate 인터페이스는 제네릭 타입으로 인자에 전달하는 값의 타입으로 선언해야함

### 12.3.2 Function 인터페이스
- Function 인터페이스 : 값을 받아 결과를 반환하는 함수를 정의할 때 사용
  - Predicate 인터페이스와 같은 패키지에 포함됨 
- Function 인터페이스에 있는 apply() 메서드는 T타입의 값을 입력 받아 R 타입의 값을 반환함 
- 형식
    ```JAVA
    public interface Function<T,R>{
        R apply(T t);
    }
    ```

<br>

- 예시 : 입력 받은 문자열을 모두 대문자로 바꾸는 코드
1. 일반 함수
```JAVA
String upperCase(String str){
    return str.toUpperCase();
}
```

2. 람다식
```JAVA
(str) -> str.toUpperCase(); 
```

3. Function 인터페이스
```JAVA
import java.util.function.Function;

public class FunctionExample {
    public static void main(String[] args){
        Function<String, String> upperCase = (str) -> str.toUpperCase();
        System.out.println(upperCase.apply("Hello world"))
    }
}
```
- 실행 결과
```JAVA
HELLO WORLD
```

### Note String 클래스의 주요 메서드 
|    메서드     |                            설명                             |
| :-----------: | :---------------------------------------------------------: |

| toLowerCase() |                 문자열을 모두 소문자로 변환                 |
|   replace()   |              일부 문자열을 다른 문자열로 대체               |

### 12.3.3 Runnable 인터페이스 
- 프로그램이 실행되면 운영체제는 프로그램을 메모리로 로드함
- 프로세스 : 프로그램을 실행하기 위해 필요한 자원을 할당하여 실행 중인 프로그램
  - 즉, 프로세스는 메모리에 로드돼 실행 중인 프로그램을 의미
- 스레드 : 프로세스의 자원을 공유하며 프로세스 내에서 독립적인 실행 흐름을 가지는 단위를 나타냄 

<br>

- Runnable 인터페이스 : 스레드를 실행할 수 있는 클래스를 정의하는데 사용되는 인터페이스
- java.lang 패키지에 포함돼 있으며 run() 메서드를 가짐
- 형태
    ```JAVA
    public interface Runnable {
        public abstract void run();
    }
    ```
- 매개변수를 받지 않고 반환형도 없음, 구현 클래스에서 run() 메서드를 정의해 스레드를 생성할 때 사용
  - 스레드가 실행할 작업을 포함

- 예시 
```JAVA
class MyRunnable implements Runnable {
    public void run(){
        System.out.println("Runnable running");
    }

    public class RunnableExample {
        public static void main(String[] args){
            MyRunnable myRunnable = new MyRunnable();
            Thread thread = new Thread(myRunnable);
            thread.start();
        }
    }
}
```

- 실행 결과 
```JAVA
Runnable running
```

- Runnable 인터페이스를 람다식으로 구현할 수도 있음 
  - Runnable 인터페이스는 java.lang 패키지에 속하여 따로 임포트하지 않아도 됨
```JAVA
public class RunnableExample{
    public static void main(String[] args){
        Runnable runnable = () -> System.out.println("run!");
        runnable.run();
    }
}
```

- 실행 결과
```JAVA
run!
```

### Note Thread 클래스 
- Thread 클래스는 자바에서 멀티 스레딩을 구현하는데 사용되는 클래스
- 자바의 모든 프로그램은 기본적으로 하나의 메인 스레드에서 시작되지만 Thread 클래스를 사용하면 여러 스레드를 생성하고 관리할 수 있음
  - 클래스를 통해 동시에 여러 작업을 수행하거나 비동기적으로 작업을 처리할 수 있음
    - 비동기로 작업을 처리 : 작업을 시작한 후 해당 작업이 완료될 때까지 기다리지 않고 다른 작업을 계속 수행할 수 있는 것을 말함
- 스레드를 생성하는 방법 2가지
  - Thread 클래스를 상속받아 run() 메서드를 오버라이드하는 방법
  - Runnable 인터페이스를 구현한 객체를 Thread 클래스의 생성자에 전달하는 방법
