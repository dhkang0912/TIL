# 12장 람다 표현식
- 함수형 프로그래밍(functional programming)은 프로그램을 수학적 함수의 조합으로 생각하는 프로그래밍 기법
  - 명확하고 이해하기 쉬운 표현식을 사용해 코드를 읽기 쉽고 유지 보수성이 좋음
  - 예 : 람다 표현식, 스트림 API
- 순수 함수 : 단일 기능으로 이루어진 함수 조합
  - 동일한 입력을 받으면 항상 동일한 결과를 반환하고 부수 효과를 일으키지 않음
    - 부수 효과 : 외부의 값을 변경함
  - 부수 효과를 일으키지 않기 때문에 코드가 안정적이고 결과가 예측 가능하며 멀티 스레드 환경에서도 안전하게 실행될 수 있음

## 12.1 람다 표현식 사용하기
- 람다 표현식 : 함수를 하나의 표현식으로 나타내는 방법
  - 람다식은 **익명 함수**로 작성함
    - 익명 함수 : 이름이 없는 함수로 함수를 따로 정의하지 않고 코드 자체를 변수에 할당해 변수처럼 사용함
  - 보통 해당 함수 프로그램에서 한번만 사용하고 다시 사용하지 않는 코드나 짧은 코드 블록을 작성할 때 사용함
  - 람다식으로 함수를 작성하면 코드가 간결해지고 코드의 가독성을 높일 수 있음
  - 형식
    ```JAVA
    ([자료형] 매개변수) -> {실행문;}
    ```
    - 소괄호에 함수에 전달되는 인자를 받는 매개변수를 넣음
    - 매개변수의 자료형은 생략할 수 있으며 매개변수가 하나일 때는 소괄호도 생략할 수 있음
    - ->는 화살표 연산자라고 하며 매개변수와 표현식을 구분하며 매개변수를 표현식에 전달하는 역할을 함
    - {}로 묶어 반환할 표현식을 넣으며 실행할 내용이 한문장이면 중괄호를 생략할 수 있음
    - 중괄호를 생략하면 return 키워드와 세미콜론도 생략하고 표현식만 작성해야함

- 예시
1. add 함수
```JAVA
int add(int a, int b){
    return a+b;
}
```

1. add 람다식
```JAVA
(int a, int b) -> a+b

// 또는

(a,b) -> a+b
```

3. isEven 함수
```JAVA
boolean isEven(int n){
    if(n%2 == 0)
        return true;
     else 
        return false;
}
```

4. isEven 람다식
```JAVA
(n) => {
    if (n%2 == 0)
        return true;
    else
        return false;
}
```

5. isEven 삼항 연산자
- 삼항 연산자
```JAVA
// 삼항 연산자 형식
(조건) ? A : B
```

- isEven 삼항 연산자
```JAVA
n -> n%2 == 0 ? true : false
```
    - 매개변수가 하나이므로 소괄호를 생략할 수 있음
    - 참 또는 거짓일 때 반환값만 남김

- 자바의 메서드와 함수형 프로그래밍의 차이
  - 자바에서 메서드는 변수를 할당할 수 없음
    - 자바에서 메서드는 클래스 안에 있어야 하고 객체를 통해 호출 가능함
    - 따라서 함수 자체를 변수에 저장하거나 다른 메서드의 인자로 넘기는 것이 불가능
  - 자바의 메서드는 클래스 안에 정의하고 객체를 생성한 후에 객체로 호출해서 사용  
    => 자바에서 클래스 없이 메서드를 함수처럼 사용하기 위해 만든 것이 람다식
  - 람다식으로 함수형 프로그래밍을 구현하기 위해 등장한 것이 `함수형 인터페이스`


## Note 메서드 참조
- 메서드 참조 : 람다식을 더 간결하게 표현하는 방법
  - 이미 존재하는 메서드를 참조해 람다식에서 사용하려 할 때 필요함
  - 메서드 참조는 :: 연산자를 사용하여 표현함

- 형식
```JAVA
객체명::메서드명 // 인스턴스 메서드 참조 시
클래스명 :: 메서드명 // 클래스 메서드 참조 시
클래스명::new // 생성자 참조 시
```
- 예 : 리스트의 모든 문자열을 대문자로 변환할 때 람다식을 사용하는 방법과 메서드 참조를 사용하는 방법을 비교
```JAVA
// 람다 표현식을 사용한 방법
words.replaceAll(s->s.toUpperCase());
// 메서드 참조를 사용한 방법
words.replaceAll(String::toUpperCase);
```

## 12.2 함수형 인터페이스 사용하기
- 람다식을 변수에 할당하려면 변수의 자료형이 필요함 => 함수형 인터페이스가 자료형 역할을 수행
  - 메서드를 클래스 내부가 아닌 다른 곳에서 사용하기 위해서는 객체를 생성하고 호출해야함
  - 클래스 없이 메서드를 함수처럼 사용하기 위해 람다식을 사용하며 람다식으로만 함수형 프로그래밍을 구현하기 위해 인터페이스를 사용

- 함수형 인터페이스 : 한 개의 추상 메서드만 가지는 인터페이스
  - 인터페이스는 직접 객체를 생성할 수 없지만 `함수형 인터페이스`는 람다식을 `함수형 인터페이스 타입의 변수에 할당해 객체처럼 사용`할 수 있음
  - 객체를 변수로 참조하듯이 `람다식을 변수로 참조`할 수 있기 때문에 객체를 생성하지 않아도 변수를 통해 람다식에 접근해 값을 전달하고 값을 반환 받을 수 있음
- 형식
    ```JAVA
    @FunctionalInterface
    interface 인터페이스명 {
        추상_메서드();
    }
    ```
    - 함수형 인터페이스를 나타내는 @FunctionalInterface 애너테이션을 추가할 수 있음

- 객체 생성 방식과 람다식을 사용한 방식의 차이 예시 : 짝수 홀수 판단
- 객체 생성 방식
1. 입력한 값이 짝수인지 확인하는 isEven() 메서드를 추상 메서드로 가진 Check 인터페이스를 정의
```JAVA
interface Check{ // 인터페이스 정의
    abstract boolean isEven(int n); // 추상 메서드 선언

}
```

2. Check 인터페이스를 구현한 EvenCheck 클래스를 다음과 같이 작성
```JAVA
interface Check{ // 인터페이스 정의
    abstract boolean isEven(int n); // 추상 메서드 선언

}

class EvenCheck implements Check{ // Check 인터페이스의 구현 클래스
    public boolean isEven(int n){
        if(n%2 == 0)
            return true;
        else
            return false;
    }
}
```

3. TraditionalExample 클래스에 main() 메서드를 생성함, EvenCheck 클래스로 객체를 생성하고 생성한 객체로 isEven() 메서드를 호출
```JAVA
public class TraditionalExample {
    public static void main(String[] args){
        EvenCheck even = new EvenCheck(); // 객체 생성
        System.out.println(even.isEven(15)); // 객체로 isEven() 메서드 호출
    }
}
```

- 람다식 사용 방식
1. Check 인터페이스에서 구현 클래스인 EvenCheck 클래스를 주석 처리 
```JAVA
@FunctionalInterface
interface Check{ // 인터페이스 정의
    abstract boolean isEven(int n); // 추상 메서드 선언
}
```

1. LamdaExample 클래스에 main() 메서드를 생성한 후 입력 값이 짝수인지 확인하는 isEven() 메서드를 람다식으로 수정
작성한 람다식을 참조할 수 있게 Check 인터페이스형으로 선언한 even 변수에 할당

```JAVA
public class LamdaExample {
    public static void main(String[] args){
        // 추상 메서드를 람다식으로 구현한 후 Check 인터페이스형 참조 변수에 할당
        Check even = n -> n%2 == 0 ? true : false;
        System.out.println(even.isEven(15)); // 변수로 isEven() 메서드 접근
    }
}
```
