# 11장 입출력 스트림
## 11.1 입출력 스트림이란
- 입출력 : 프로그램이 컴퓨터 내/외부 장치와 데이터를 주고 받는 것
- 스트림 : 프로그램에서 데이터를 주고 받기 위해 사용하는 개념
  - 자바에서 데이터를 주고 받을 때 사용하는 가상의 통로
  - 데이터의 흐름을 물줄기에 비유해 붙인 이름으로 한 방향으로 흐르듯이 스트림도 한 방향으로만 전달할 수 있음
    - 입력 스트림과 출력 스트림으로 나뉨

<br>

- 입력 스트림 : 외부로부터 데이터를 읽어들이는 스트림
  - 키보드 입력, 파일, 네트워크 소켓(네트워크와 컴퓨터 연결 창구) 등이 해당
- 출력 스트림 : 데이터를 외부로 내보내는 스트림
  - 파일로 데이터를 저장하거나 네트워크 소켓을 통해 데이터를 전송할 때 사용

![alt text](<자바의 입출력 스트림.png>)

#### 스트림의 특징
- 순차적으로 데이터를 읽고 써서 먼저 입력된 데이터가 먼저 출력되는 FIFO(선입선출) 형태로 동작
- 스트림은 버퍼를 사용함
  - 버퍼 : 데이터를 일시적으로 저장하기 위한 메모리 영역
  - 버퍼링 : 스트림은 데이터를 한번에 하나씩 전송하기 때문에 버퍼를 통해 데이터를 한번에 모아 처리함 => 입출력 효율이 크게 향상됨
- 작업이 끝나면 스트림을 닫고 관련 자원을 해제해야함 
  - 해제를 하지 않으면 메모리가 낭비될 수 있고 파일이 잠금 상태가 돼 다른 프로그램에서 해당 파일에 접근할 수 없는 문제가 발생함

## 11.2 스트림의 종류
- 스트림 : 바이트 스트림과 문자 스트림으로 나뉨
  - 바이트 스트림 : 바이트 단위 데이터 처리, 주로 비텍스트 데이터를 처리
  - 문자 스트림 : 문자 단위로 데이터 처리, 주로 덱스트 데이터를 처리 

### 11.2.1 바이트 스트림
- 바이트 스트림 : 데이터를 1바이트(8비트) 단위로 처리함 
  - 주로 바이너리 데이터를 다룰 때 사용
    - 바이너리 데이터 : 0과 1로 표현된 데이터로 이미지, 오디오, 비디오, 실행 파일 등을 표현할 때 사용
  - 자바에서는 다양한 종류의 스트림을 처리할 수 있도록 java.io 패키지를 제공
    - 다양한 클래스를 포함하는데 그 중 바이트 스트림을 처리하기 위한 클래스로는 `InputStream`과 `OutputStream`이 있음

#### `InputStream`
- InputStream 클래스는 바이트 입력 스트림을 위한 추상 클래스
- 프로그램 외부에서 데이터를 바이트 단위로 읽어옴
- 추상 클래스이므로 직접 객체를 생성할 수는 없고 상속받은 클래스들로 구체적인 기능이 구현 가능

<br>

- 주요 하위 클래스
1. FileInputStream : 파일에서 바이트 단위로 데이터를 읽어오는 입력 스트림 클래스 
2. ByteArrayInputStream : 메모리에 있는 바이트 배열에서 데이터를 읽어올 때 사용하는 클래스 
3. BufferedInputStream : 보조 스트림 클래스로 바이트 스트림에 버퍼링 기능을 제공
    - 기본 버퍼 크기 : 8,192 바이트
    - 크기를 지정할 수도 있음
    - FilterInputStream 클래스를 상속받음
4. DataInputStream : 기본형과 문자열 데이터를 읽어오는데 사용하는 클래스

#### `OutputStream`
- OutputStream 클래스는 바이트 출력 스트림을 처리하기 위한 추상 클래스
- 외부로 데이터를 바이트 단위로 내보냄 

<br>

- 주요 하위 클래스
1. FileOutputStream : 파일에 바이트 데이터를 쓸 때 사용
2. ByteArrayOutputStream : 메모리에 있는 바이트 배열에 데이터를 쓰기 위해 사용
3. BufferedOutputStream : 버퍼를 사용해 데이터를 더 효율적으로 쓸 수 있게 도와줌
4. DataOutputStream : 기본형 문자열 데이터를 바이트 스트림으로 변환해서 출력할 수 있게 함

### 11.2.2 문자 스트림
- 문자 스트림 : 2바이트(16비트) 유니코드 문자 단위로 데이터를 처리 
- 주로 텍스트 파일이나 문자 데이터를 처리하는데 사용
- 다양한 문자 인코딩을 지원해 한글과 같은 **유니코드 문자를 올바르게 읽거나 쓸 수 있음**
- 문자 스트림을 다루기 위한 java.io 패키지 클래스로 **Reader**와 **Writer**가 있음

#### `Reader 클래스`
- 문자 입력 스트림을 위한 추상 클래스로 외부에서 문자를 읽어오는데 사용

<br>

- 주요 하위 클래스
1. FileReader : 파일에서 문자 단위(2바이트)로 데이터를 읽어옴
2. BufferedReader : 문자를 더 효율적으로 읽을 수 있는 버퍼링 기능을 제공
    - 특히 readLine() 메서드로 데이터를 한 줄 씩 읽어올 때 자주 사용
3. InputStreamReader : 바이트 스트림을 문자 스트림으로 변환하는 기능을 제공
    - 주로 키보드 입력이나 네트워크 소켓으로 들어온 데이터를 읽을 때 사용
4. StringReader : 문자열에서 문자를 읽는데 사용

#### `Writer 클래스` 
- 문자 출력 스트림을 위한 추상 클래스로 문자 데이터를 외부로 출력하거나 파일에 데이터를 쓸 때 사용

<br>

- 주요 하위 클래스 
1. FileWriter : 파일에 문자 데이터를 쓸 때 사용
2. BufferedWriter : 버퍼링을 사용해 문자를 더 효율적으로 쓸 수 있게 도움
3. OutputStreamWriter : 문자 스트림을 바이트 스트림으로 변환해줌
4. StringWriter : 문자열 데이터를 메모리의 버퍼에 쓸 수 있음
    - 주로 문자열 조작이나 임시 버퍼링에 사용함
5. PrintWriter : 다양한 자료형의 데이터를 문자로 변환해 쓸 수 있음

## 11.3 파일 입출력
- 파일 입출력 : 외부에 저장된 데이터를 읽거나 프로그램의 데이터를 파일로 저장하는 작업
  - 예 : 텍스트 파일에서 데이터를 읽거나 이미지 파일을 메모리에 로드하는 작업, 계산 결과를 파일에 저장하거나 로그를 파일에 기록하는 작업
- 주로 FileInputStream, FileOutputStream, FileReader, FileWriter 클래스를 사용함

### 11.3.1 파일에서 입력 받기
- 파일 입력 작업에는 주로 FileInputStream, FileReader 클래스를 사용함

#### FileInputStream
- FileInputStream 클래스는 파일에서 데이터를 바이트 단위로 읽어옴 
- 이미지 파일, 오디오 파일, 비디오 파일 등 바이너리 데이터를 읽어올 때 사용함
- 주어진 파일 또는 File 객체로 지정된 파일에서 데이터를 읽어옴

<br>

- FileInputStream 클래스의 주요 메서드

|            메서드             |                                       설명                                        |
| :---------------------------: | :-------------------------------------------------------------------------------: |
|            read()             |    파일에서 1바이트씩 데이터를 읽어 정수로 반환, 파일 끝에 도달하면 -1을 반환     |
|       read(바이트_배열)       |       파일에서 바이트 배열의 크기만큼 데이터를 읽고, 읽은 바이트 수를 반환        |
| read(바이트_배열, 위치, 길이) | 파일에서 길이(바이트 단위)만큼 데이터를 읽어 바이트 배열의 지정 위치에서부터 저장 |
|            close()            |                          스트림을 닫고 관련 자원을 해제                           |

- 예시
    ```JAVA
    package ch11;

    import java.io.FileInputStream;
    import java.io.IOException;

    public class FileInputStreamExample {
        public static void main(String[] args){
            // 객체를 생성해 스트림을 열게 됨
            // close() 메서드로 스트림을 닫는 대신
            // try-with-resources 문법을 사용해 자동으로 닫음
            try (FileInputStream fis = new FileInputStream("D:/input.txt")){
                int data;
                // data에 1바이트씩 저장
                // read()를 통해 1바이트씩 데이터를 읽고 더 읽을 데이터가 없으면 -1 반환
                while ((data = fis.read())!=-1){
                    System.out.print((char) data); // 문자로 변환하여 출력
                }
            } catch (IOException e) {
                // 예외가 발생한 순간부터 메서드 호출이 어떤 경로를 따라왔는지에 대한 정보를 출력
                e.printStackTrace();
            }
        }
    }

    ```
- 실행 결과
    ```java

    Read data from the file. 

    // 실패 시

    at java.base/java.io.FileInputStream.<init>(FileInputStream.java:106)

    ```

- try-with-resources 문법
  - 자바 7 버전에서 도입된 문법으로 사용된 자원을 자동으로 안전하게 닫아주는 기능
  - close() 메서드로 명시적으로 닫지 않아도 자원이 자동으로 닫혀 메모리 낭비를 방지
  - 코드의 안정성과 가독성이 향상됨
  - 형식
    ```JAVA
    try (자원_클래스 변수 = new 자원_클래스()){
        // 자원 사용 코드
    } catch (예외_클래스 변수){
        // 예외 처리 코드
    }
    ```

#### FileReader/BufferedReader 클래스
- FileReader 클래스는 파일에서 문자 단위로 데이터를 읽어오는데 사용함
  - 주로 텍스트 파일을 읽어올 때 사용
  - FileReader 클래스는 성능 개선을 위해 BufferedReader 클래스와 함께 사용하는 것이 일반적
- BufferedReader 클래스는 버퍼를 사용해 데이터를 한번에 읽고 한줄 단위로 처리하는 기능을 제공

<br>
- FileReader 클래스는 FileInputStream 클래스의 메서드와 읽어오는 데이터 단위만 다르고 거의 동일

<br>

- BufferedReader 클래스의 주요 메서드

|   메서드   |                                               설명                                               |
| :--------: | :----------------------------------------------------------------------------------------------: |
| readLine() |                  한 줄을 읽어 문자열로 변환, 더 이상 읽을 줄이 없으면 null 반환                  |
|  ready()   |            입력 스트림에서 읽을 준비가 됐는지, 즉 버퍼에 읽을 데이터가 있는지 확인함             |
|  close()   | 스트림을 닫고 관련된 시스템 자원을 모두 해제, try-with-resources 문법을 사용하면 자동으로 호출됨 |

- 예시
    ```JAVA
    package ch11;

    import java.io.BufferedReader;
    import java.io.FileReader;
    import java.io.IOException;

    public class FileReaderExample {
        public static void main(String[] args){
            // FileReader 객체를 생성해 스트림을 열고 이를 인자로 받아 BufferedReader 객체를 생성
            // BufferedReader 객체는 스트림을 감싸서 FileReader 객체가 읽어온 데이터를 버퍼에 저장
            try(BufferedReader br = new BufferedReader(new FileReader("/Users/sarah/Desktop/Coding/SSAFY/SSAFY Data/SSAFY_study/TIL/TIL Traces/Java/코딩 자율학습 자바 입문/firstjavaproject/src/ch11/txt.txt"))){
                String line; // 읽어들인 텍스트 한 줄을 저장할 변수
                // BufferedReader 객체의 버퍼에서 텍스트 한줄씩 읽어와 line에 저장
                // 더 이상 줄이 없으면 null을 반환하기 때문에 null이 나올 때까지 반복
                while ((line = br.readLine())!=null){
                    System.out.print(line);
                }
                // try-with-resources 문법에 의해 try 블록 완료 후 스트림이 자동으로 닫힘
            } catch (IOException e){
                e.printStackTrace();
            }
        }
    }

    ```
- 실행 결과
    ```JAVA
    input text
    ```
### 11.3.2 파일에 출력하기
- 파일 출력 작업에는 주로 FileOutputStream과 FileWriter 클래스를 사용

#### FileOutputStream 클래스
- FileOutputStream 클래스는 파일에 바이트 단위로 데이터를 씀
  - 주로 바이너리 데이터를 파일에 저장할 때 사용
  - 주어진 파일 또는 File 객체로 지정된 파일에 데이터를 씀
  - FileOutputStream 객체를 생성할 때 지정한 파일이 존재하지 않으면 자동으로 파일이 생성되며 이미 존재한다면 내용을 덮어씀

- FileOutputStream 클래스의 주요 메서드 

|             메서드             |                                  설명                                  |
| :----------------------------: | :--------------------------------------------------------------------: |
|            write()             |                       1바이트 데이터를 파일에 씀                       |
|       write(바이트_배열)       |                    바이트 배열의 데이터를 파일에 씀                    |
| write(바이트_배열, 위치, 길이) | 바이트 배열의 지정된 위치에서부터 지정된 길이만큼의 데이터를 파일에 씀 |
|            close()             |                     스트림을 닫고 관련 자원을 해제                     |

- 예시
    ```JAVA
    package ch11;

    import java.io.FileOutputStream;
    import java.io.IOException;

    public class FileOutputStreamExample {
        public static void main(String[] args){
            String data = "Hello World!";
            // 예외처리를 위해 try-catch 블록을 사용
            try {
                // FileOutputStream 객체를 생성해 스트림을 연다
                FileOutputStream fos = new FileOutputStream("/Users/sarah/Desktop/Coding/SSAFY/SSAFY Data/SSAFY_study/TIL/TIL Traces/Java/코딩 자율학습 자바 입문/firstjavaproject/src/ch11/txt.txt");
                    fos.write(data.getBytes()); // getBytes를 통해 data 변수의 문자열을 바이트 배열로 변환
                    fos.close();
                System.out.println("Writing Completed.");
            } catch (IOException e){
                e.printStackTrace();
            }
        }
    }

    ```
- 실행 결과
    ```JAVA
    Writing Completed.
    ```

#### FileWriter / BufferedWriter 클래스
- FileWriter 클래스는 파일에 문자 단위로 데이터를 씀
- 텍스트 파일이나 로그 파일 등 문자열 데이터를 저장할 때 사용
- 단순한 파일 쓰기 작업에 자주 사용함
- 기본적으로 파일을 덮어쓰지만 append 모드를 사용하면 파일 끝에 데이터를 추가할 수 있음
- BufferedWriter 클래스와 함께 사용하면 버퍼링 기능을 사용해 성능을 높일 수 있음

<br>

- FileWriter 클래스는 FileOutputStream 클래스의 메서드와 쓰는 데이터 단위만 다르고 거의 유사

<br>

- BufferedWriter 클래스의 주요 메서드 

|    메서드     |               설명               |
| :-----------: | :------------------------------: |
| write(문자열) |     전체 문자열을 버퍼에 씀      |
|   newLine()   |          새 줄을 추가함          |
|    flush()    | 버퍼에 있는 모든 데이터를 출력함 |

- 예시
    ```JAVA
    package ch11;

    import java.io.BufferedWriter;
    import java.io.FileWriter;
    import java.io.IOException;

    public class FileWriterExample {
        public static void main(String[] args){
            // try-with-resources 문법으로 FileWriter와 BufferedWriter 객체 생성
            // FileWriter 객체 생성 시 파일 명과 함께 두번째 인자를 true로 하면 append 모드로 열림 => 파일 끝에 새로운 내용 추가
            try (BufferedWriter writer = new BufferedWriter(new FileWriter("/Users/sarah/Desktop/Coding/SSAFY/SSAFY Data/SSAFY_study/TIL/TIL Traces/Java/코딩 자율학습 자바 입문/firstjavaproject/src/ch11/txt.txt", true))){
                // 줄 바꿈을 파일에 추가
                writer.newLine();
                // 문자 추가
                writer.write("Hello, java");
                // 줄 바꿈을 파일에 추가
                writer.newLine();
                // 문자 추가
                writer.write("This is another line.");
            }catch (IOException e){
                e.printStackTrace();
            }
        }
    }
    ```
