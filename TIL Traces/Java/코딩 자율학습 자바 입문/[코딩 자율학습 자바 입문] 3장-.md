# 3장 기초 문법 배우기
## 3.1 변수
- 입력 : 명령을 실행하는데 필요한 데이터를 넣어주는 것
- 저장 : 입력한 데이터를 프로그램에서 사용하기 위해 컴퓨터 어딘가에서 기억하고 있는 것
- 변수 : 프로그램이 데이터를 저장하기 위해 할당 받은 메모리 공간

### 3.1.1 변수 선언
- 변수 선언 : 프로그램이 메모리 공간을 할당 받기 위해 변수를 만드는데, 이를 변수 선언이라고 함

- 자바에서의 변수 선언
  ```java
  자료형 변수명;
  ```
  - 자료형 + 선언할 변수명(변수 이름) + ;

- 자료형 (데이터 타입) : 변수에 저장하는 데이터의 형태
- 변수명을 지을 때 규칙
  1. 대소문자를 구분하고 길이 제한은 없음
  2. 숫자로 시작하지 않음
  3. 특수문자는 _와 $만 허용
  4. 공백이 없어야 함
  5. 키워드를 사용하면 안됨

### 3.1.2 변수 초기화
- 변수를 선언한다고 바로 메모리 공간이 할당되지 않음
- 변수 선언은 프로그램에서 만든 변수에 어떤 변수를 저장할 수 있는지를 자바 컴파일러에 알려주는 역할
- 프로그램에서 변수에 데이터를 넣으면 데이터가 변수에 저장되고 이 때 메모리가 할당됨

- 값 : 변수에 넣는 데이터
- 값이 저장되면 변수명으로 메모리에 접근해 사용할 수 있음
