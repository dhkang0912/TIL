# 3장 기초 문법 배우기
## 3.1 변수
- 입력 : 명령을 실행하는데 필요한 데이터를 넣어주는 것
- 저장 : 입력한 데이터를 프로그램에서 사용하기 위해 컴퓨터 어딘가에서 기억하고 있는 것
- 변수 : 프로그램이 데이터를 저장하기 위해 할당 받은 메모리 공간

### 3.1.1 변수 선언
- 변수 선언 : 프로그램이 메모리 공간을 할당 받기 위해 변수를 만드는데, 이를 변수 선언이라고 함

- 자바에서의 변수 선언
  ```java
  자료형 변수명;
  ```
  - 자료형 + 선언할 변수명(변수 이름) + ;

- 자료형 (데이터 타입) : 변수에 저장하는 데이터의 형태
- 변수명을 지을 때 규칙
  1. 대소문자를 구분하고 길이 제한은 없음
  2. 숫자로 시작하지 않음
  3. 특수문자는 _와 $만 허용
  4. 공백이 없어야 함
  5. 키워드를 사용하면 안됨

### 3.1.2 변수 초기화
- 변수를 선언한다고 바로 메모리 공간이 할당되지 않음
- 변수 선언은 프로그램에서 만든 변수에 어떤 변수를 저장할 수 있는지를 자바 컴파일러에 알려주는 역할
- 프로그램에서 변수에 데이터를 넣으면 데이터가 변수에 저장되고 이 때 메모리가 할당됨

- 값 : 변수에 넣는 데이터
  - 값이 저장되면 변수명으로 메모리에 접근해 사용할 수 있음

``` java
int a;
int b = 10;
```
- 컴퓨터가 이 코드를 읽으면 메모리에서 사용할 수 있는 빈 공간을 찾아 a, b라는 이름을 붙이고, b에는 10이 저장됨

```java
public class Main {
    public static void main(String[] args) {
        //TIP Press <shortcut actionId="ShowIntentionActions"/> with your caret at the highlighted text
        // to see how IntelliJ IDEA suggests fixing it.
//        Scanner scan = new Scanner(System.in);
//        System.out.println(scan.nextLine());
//        System.out.println(scan.next());
//        scan.close();
        int a;
        int b = 10;
        a = 11;
        System.out.println(a);
        System.out.println(b);
    }
}
```
- 선언만 하고 출력하면 에러가 남
- 초기화는 변수 선언과 동시에 해도 되고, 나중에 따로 해도 되지만 사용하기 전엔 반드시 해야함

```java
int number1, number2, number3;
int a=0, b=0, c=0;
```
- 자료형이 같으면 여러 변수를 한번에 선언하고 초기화할 수도 있음
- 변수 여러 개를 한꺼번에 선언하면 코드가 복잡해지고 헷갈리니 익숙해지기 전까지는 각각 선언하기

### 3.1.3 변수 표기법
- 코드에서 변수명, 클래스명과 같은 이름을 작성할 때 주로 사용하는 4가지 표기법

1. 카멜 표기법 (camel case)
- 자바에서 변수명을 지을 때 사용됨
- 가장 유명한 표기법으로 낙타 등을 닮아서 지어짐
- 첫 글자는 소문자로 시작하고 여러 단어로 구성되면 첫 단어 외에 각 단어의 첫글자를 대문자로 표기
- `int firstNumber;`
2. 파스칼 표기법 (pascal case)
- 자바에서 클래스명을 지을 때 사용함
- 모든 단어의 첫글자를 대문자료 표기함
- `int FirstNumber;`
3. 스네이크 표기법 (snake case)
- 모든 단어를 소문자로 표기하고 여러 단어일 때 뱀처럼 생긴 _로 단어를 연결함
- 언더바 표기법이라고도 함
- `int first_number;`
4. 헝가리안 표기법 (Hungarian notation)
- 자료형을 파악하기 쉽게 접두어(첫번째 단어)를 붙이는 표기법
- 마이크로소프트의 헝가리 출신 개발자인 찰스 시모니가 사용하던 방식
- `int intNumber;`
- `String strName;`
- `String txtMyName;`

## 3.2 자료형
### 3.2.1 기본 자료형
- 변수 선언 형식에서 변수 명 앞 자료형을 표시
  - `자료형 변수명 = 값`
- 자료형 : 변수에 저장하는 값의 형태

- 정수형 변수 : 정수 값을 저장하는 변수
  - **기본적으로 int (integer)**를 사용
    - `int intNum = 123;`
  - 정수형 변수는 값의 크기에 따라 **byte(1바이트), short(2바이트), int(4바이트), long(8바이트)**를 사용할 수 있음
    - long일 때만 L 또는 l을 붙여 구분
      - `long longNum = 45678910L;`

- 실수형 변수 : 소수점이 있는 형태의 수를 저장하는 변수
  - float(4바이트), double(8바이트)
    - 값의 크기에 따라 구분하고 **double을 기본**으로 사용
    - float 일 때는 값 뒤에 F 또는 f를 붙여 구분
      - `float floatNum = 123.4F;`
      - `double doubleNum = 123.4;`

- 문자형 변수 : 문자를 저장
  - char (2바이트) 사용, 작은따옴표 사이에 넣음
  - 숫자로 작은 따옴표에 넣으면 문자로 인식
    - `char charTxt = 'a';`
    - `char charNum = '1';`

- 논리 자료형 변수 : 참(true), 거짓(false)만 가짐
  -  boolean(1바이트)을 사용해 표시
  -  `boolean isTrue = true;`

- 변수에 저장하는 값의 종류와 크기에 따라 변수명 앞에 붙는 자료형 키워드가 달라짐

### 3.2.2 문자열
- String : 문자열로된 값을 표시할 때 사용, 기본 자료형 외에도 자주 사용하는 자료형
  - 큰따옴표로 표시하고 큰따옴표 사이에 숫자나 문자를 넣으면 문자열로 인식
  - 기본 자료형이 아닌 참조 자료형
    - 참조 자료형 : 값을 저장하는 기본 자료형과 달리 값이 저장된 주소를 저장하여 메모리에서 위치를 나타냄 
      - 배열, 클래스, 인터페이스 등이 있음
    - `String strTxt = "a";`
    - `String strWord = "Java";`
    - `String strNum = "123";`
    - `String strKor = "코딩 자율학습";`

- 타입 추론
  - Java 9까지는 변수를 선언할 때 자료형을 반드시 명시했지만 10부터는 var로 변수를 선언할 수 있음
  - `var b = 10;`
  - 컴파일러가 값을 보고 자료형을 추론해 정수형 변수를 선언함
  - 컴파일러가 개발자의 의도를 추측한다고 하여 이를 **타입 추론**라고 함

### 3.2.3 prinf()로 서식 지정해서 출력하기
- 원하는 형식으로 내용을 출력하고 싶다면 prinf()를 사용함
- `System.out.prinf("서식_지정자", 값);`
  - prinf()의 소괄호 안에 서식 지정자를 넣고 쉼표로 구분해 값을 넣으면 정해진 형식에 맞춰 값을 출력함
  - 이때 서식 지정자는 큰따옴표로 감싸줌
  - 서식 지정자는 **형식 지정자**라고도 하며, 뒤에 오는 값을 어떻게 화면에 출력할지 형태를 지정해줌

#### 서식지정자
| 서식지정자 |  출력형태   |
| :--------: | :---------: |
|     %d     |    정수     |
|     %f     |    실수     |
|     %c     |    문자     |
|     %s     |   문자열    |
|     %b     |  논리형 값  |
|     %t     | 시간과 날짜 |
|     %n     |   줄 바꿈   |
|     %%     |   % 기호    |

- 예시
```java
public class Main {
    public static void main(String[] args) {
        System.out.printf("이름: %s%n", "코천이");
        System.out.printf("나이: %d\n", 21);
        System.out.printf("취미: %s%n", "코딩");

        System.out.printf("이름: %s%n나이: %d\n취미: %s%n", "코천이",21,"코딩");

    }
}
```
- 실행결과
```
이름: 코천이
나이: 21
취미: 코딩
이름: 코천이
나이: 21
취미: 코딩
```
- printf()에 서식 지정자를 여러개 넣으면 뒤에 오는 값이 순서대로 서식 지정자 위치로 들어가 출력됨
- 서식 지정자의 개수와 값의 개수가 같아야 하고 출력 형태에 맞는 값을 넣어야 함
![Alt text](<서식 지정자와 값의 매칭.png>)

- 서식 지정자의 %뒤에 숫자를 넣어 자릿수를 맞출 수도 있음
- 플래그를 함께 넣으면 빈자리에 채울 내용을 지정할 수 있음

#### 서식 지정자에 사용하는 플래그

|   플래그    |                        설명                        |
| :---------: | :------------------------------------------------: |
| 플래그 없음 |       오른쪽 정렬하고 빈자리를 공백으로 채움       |
|      -      |        왼쪽 정렬하고 빈자리를 공백으로 채움        |
|      0      |                빈자리를 0으로 채움                 |
|      ,      | 천 단위 구분 기회(,)를 넣고 빈자리를 공백으로 채움 |

- 예시
```java
public class Main {
    public static void main(String[] args) {
        System.out.printf("%7d%n", 11111);
        System.out.printf("%-7d%n", 11111);
        System.out.printf("%07d%n", 11111);
        System.out.printf("%,7d%n", 11111);
    }
}
```
- 실행 결과
```
  11111
11111  
0011111
 11,111
```
- %뒤에 7자리수로 고정하고 각 플래그에 맞게 출력됨
![Alt text](<서식 지정자 주요 플래그.png>)

#### 소수점 출력
- 서식 지정자에 **.숫자** 형태로 출력할 소수점 이하 자릿수를 넣어줌

- 예시
```java
public class Main {
    public static void main(String[] args) {
        System.out.printf("%.4f", 123.45f);
    }
}
```
- 실행 결과
```
123.4500
```
- 실수 123.45를 소수점 이하 4자리까지 출력하고 빈자리를 0으로 채움
