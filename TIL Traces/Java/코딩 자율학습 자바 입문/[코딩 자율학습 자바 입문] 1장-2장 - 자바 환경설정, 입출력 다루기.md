# 1장 Hello Java
## 1.1 자바 개발 환경 설정
- JDK(Java Development Kit) : 자바에서 프로그램을 작성하는데 필요한 것들을 모아 제공함
- IDE(Integrated Development Environment) : 프로그램을 개발하는 데 유용한 도구의 집합
  - 자바용 : Eclipse, IntelliJ IDEA

### 1.1.1 JDK 설치하기
- 하단 사이트에서 운영체제에 맞는 JDK 21을 다운받기
  - https://www.oracle.com/java/technologies/downloads/
- 제대로 설치 됐는지 명령 프롬포트 실행해보기
  - 윈도우 : cmd 들어가서 `java -version` 입력하여 version이 나오면 잘 깔린 것

### 1.1.2. 인텔리제이 설치하기
- 하단 사이트에서 운영체제에 맞는 인텔리제이 24.1.6 버전 다운받기 (다른 걸로 받아도 됨)
  - https://www.jetbrains.com/ko-kr/idea/download/other.html
  - 다운 받은 후 projects 생성하기
    - Build System : 빌드(작성한 소스 코드를 실행할 수 있는 파일로 바꾸는 과정)를 할 때 사용하는 프로그램 (빌드 도구), 기본값인 Intellij를 그대로 두면 됨

## 1.2 첫번째 자바 프로젝트
- 자바 소스 코드 보기
```java
//TIP To <b>Run</b> code, press <shortcut actionId="Run"/> or
// click the <icon src="AllIcons.Actions.Execute"/> icon in the gutter.
public class Main {
    public static void main(String[] args) {
        //TIP Press <shortcut actionId="ShowIntentionActions"/> with your caret at the highlighted text
        // to see how IntelliJ IDEA suggests fixing it.
        System.out.printf("Hello and welcome!");

        for (int i = 1; i <= 5; i++) {
            //TIP Press <shortcut actionId="Debug"/> to start debugging your code. We have set one <icon src="AllIcons.Debugger.Db_set_breakpoint"/> breakpoint
            // for you, but you can always add more by pressing <shortcut actionId="ToggleLineBreakpoint"/>.
            System.out.println("i = " + i);
        }
    }
}
```
  - Class
    - Class : 프로그램을 구성하는 기본 단위
      -  자바 프로그램은 1개 이상의 클래스로 구성됨
      - 클래스명은 자바 파일명과 동일하게 작성하고 첫글자는 대문자로 시작함
      - public이 붙은 클래스는 한 파일에 1개만 존재하며, 한 프로그램 안에 클래스가 2개 이상 존재할 수 있음
      - 클래스명 뒤 {}를 사용
      - 명령이 끝나면 ;를 붙임
  - Main method
    - main()은 클래스에 포함된 메서드로 프로그램의 시작점을 의미
    - 클래스 전체에서 main() 메서드는 하나만 존재할 수 있음
    - main() 메서드 뒤에도 {}가 옴

# 2장 입출력 다루기
- 입력 : 명령에 필요한 데이터를 입력
- 출력 : 입력받은 데이터로 명령을 수행한 결과를 보여주는 것
  - 입출력(I/O)

## 2.1 출력하기
- 자바에서 대표적인 출력 명령어 
  - print()
  - println()
  - printf()

- 자바 프로그램은 JVM 위에서 실행되기 때문에 프로그램에서 직접 운영체제에 접근할 수 없음
  - 일반 프로그램 : 프로그램 <=> 운영체제 <=> 하드웨어
  - 자바 프로그램 : 프로그램 <=> JVM <=> 운영체제 <=> 하드웨어
  - 자바 프로그램에서 운영체제의 기능인 프로그램 종료, 키보드 입력, 메모리 정리, 현재 시간 읽기, 시스템 속성, 환경 변수 읽기, 화면 출력 등을 사용하려면 연결 고리가 필요함  
  => 이 연결 고리가 System 클래스, 출력 명령어 앞에 System 클래스를 연결해 사용함

### 2.1.1 print()로 출력하기
- `System.out.print("Hello");`
  - 줄을 바꾸지 않는 출력문
  - `\n`을 사용하면 줄을 바꿀 수 있음 => 개행 문자, 줄바꿈 문자
- `System.out.println("Hello");`
  - 출력하고 자동으로 줄을 바꿔줌
  - ln은 line을 뜻하며 프린트 라인이라고 읽음
  - 인텔리제이에서 `sout`을 입력하고 엔터를 치면 println이 입력됨

## 2.2 입력받기
- 출력이 명령을 실행한 결과를 화면으로 보여주는 것이라면, 입력은 명령을 실행하는데 필요한 데이터를 넣어주는 것

### 2.2.1 read()로 입력받기
- read()
  - `System.in.read()`
  - 대표적인 입력 명령어
  - 키보드로 값을 입력 받으라는 의미
  - 명령어만 읽어오기 때문에 출력을 바로 하거나, 입력된 값을 저장해야 함
  - 아스키 코드로 입력 받음
  - `System.out.println(System.in.read());`
    - 입력값을 바로 출력하는 명령어
    - 빨간 줄이 뜨며 예외처리가 되지 않았다고 뜸 => add exception to method signature 클릭 (throws IOException 추가됨)
      - 빨간 줄의 의미
        - 오류
        - 예외 : 이 경우 미리 예외 처리를 해줘야 함
  - `System.out.println((char)System.in.read());`
    - 아스키 코드가 아닌 입력 값을 그래도 받아 출력하는 방법

### 2.2.2 Scanner 클래스로 입력받기
- 스트림 : 입출력 장치와 프로그램을 연결하는 통로
  - 자바 입출력이 스트림을 통해 이루어짐
  - 입력 장치를 입력한 값은 **입력 스트림**을 통해 프로그램으로 전달되고, 프로그램을 실행한 결과는 **출력 스트림**을 통해 출력 장치에 표시됨
  - System.in = 입력 스트림
  - System.in = 출력 스트림
- read()는 1바이트만 읽어오고 2 바이트 이상을 사용할 수 없음 => Scanner 클래스 사용


- Scanner 사용법
  - `Scanner scan = new Scanner(System.in);`
    - scan이라는 변수에 저장
  - `System.out.println(scan.nextLine());`
    - nextLine은 Scanner 클래스에 속한 명령어
    - 한 줄 단위로 입력을 받을 수 있음
    - 사용자가 엔터를 입력하기 전까지 모든 내용이 출력됨
    - 사용자가 값을 입력하면 scan 변수에 저장되고 nextLine()으로 한줄씩 읽어오고 println()로 출력함
  - `System.out.println(scan.next());`
    - 입력 받은 내용 중 공백 문자 전까지 출력
    - 이렇게 출력 명령어가 있는만큼 입력을 받게 됨
  - `scan.close();`
    - Scanner 클래스로 입력 스트림을 사용하다가 사용이 끝나면 close() 명령어로 닫아주는 것이 좋음
    - 그렇지 않으면 계속 자원을 사용하는 상태가 되어 메모리가 낭비됨
