# 6장 여러 값 한 번에 저장하기: 배열
## 6.1 배열의 기본
### 6.1.1 배열이란
- 변수 : 어떤 자료형의 값을 저장하기 위한 공간
- 배열 : 같은 자료형의 값 여러개를 변수 하나로 묶어 관리하는 것
  - 정수는 정수끼리, 문자열은 문자열끼리 묶어 저장할 수 있음
- 형식
    ```java
    int[] scoreArray = {80, 90, 100, 70};
    ```
- 배열과 변수의 구조 비교
![alt text](<배열과 변수의 구조 비교.png>)
- 배열은 같은 유형의 데이터를 효율적으로 관리하기 위해 필요

### 6.1.2 배열 선언하고 초기화하기
- 배열 선언
- 형식
    ```java
    자료형[] 배열명;
    ```
- 예시
  ```java
  int[] ages; // 정수형 배열 선언
  String[] names; // 문자열 배열 선언
  ```

- 배열 초기화 방식
1. 선언과 동시에 값을 넣어 초기화하기
```java
자료형[] 배열명 = {값1, 값2, ...}
```
- 배열을 선언하고 대입 연산자(=)로 초기화
- 값은 중괄호({}) 안에 넣기
- 값이 여러 개일 때는 쉼표(,)로 구분
- 중괄호 뒤에는 세미콜론(;) 붙이기
- 초깃값의 개수에 따라 배열 크기가 자동으로 결정됨
- 배열에 담긴 값의 자료형은 모두 동일해야함

2. 배열의 크기를 지정해 생성하기
- new 키워드 사용
```java
자료형[] 배열명 = new 자료형[배열_크기];
```
- 크기를 지정해 배열 선언 시 **자료형의 기본값으로 초기화**됨
- 자료형별 기본값

| 자료형 |      기본값       |
| :----: | :---------------: |
| 정수형 |         0         |
| 실수형 |        0.0        |
| 문자형 | \u0000(null 문자) |
| 논리형 |       false       |
| 문자열 |       null        |

- 예시
```java
int[] scoreArray = new int[4]
```
- 크기가 4인 정수형 배열을 선언하고 값을 모두 0으로 초기화

### 6.1.3 배열에 접근하기
- 요소 : 배열에 저장된 값
- 인덱스 : 요소의 위치를 나타냄
- 배열에서는 요소의 위치를 나타내는 **인덱스**를 사용하여 접근함
- 배열의 인덱스는 항상 **0**부터 시작
- 형식
    ```java
    배열명[인덱스]
    ```
- 예시
```java
public class Main {
    public static void main(String[] args) {
        int[] scoreArray = {80, 90, 100, 70};
        scoreArray[0] = 50; // 값 변경
        scoreArray[1] = 60; // 값 변경
        scoreArray[2] = 70; // 값 변경
        scoreArray[3] = 80; // 값 변경
        System.out.println("1번 학생의 점수: " + scoreArray[0]);
        System.out.println("2번 학생의 점수: " + scoreArray[1]);
        System.out.println("3번 학생의 점수: " + scoreArray[2]);
        System.out.println("4번 학생의 점수: " + scoreArray[3]);
    }
}
```
- 실행 결과
```java
1번 학생의 점수: 50
2번 학생의 점수: 60
3번 학생의 점수: 70
4번 학생의 점수: 80
```
- 모두 재할당한 새로운 값으로 변경된 것을 확인할 수 있음

- 활용 : 배열 크기로 배열 선언 시 새로운 값 저장하기
```java
public class Main {
    public static void main(String[] args) {
        int[] scoreArray = new int[4];
        scoreArray[0] = 80;
        scoreArray[1] = 90;
        scoreArray[2] = 100;
        scoreArray[3] = 70;
        System.out.println("1번 학생의 점수: " + scoreArray[0]);
        System.out.println("2번 학생의 점수: " + scoreArray[1]);
        System.out.println("3번 학생의 점수: " + scoreArray[2]);
        System.out.println("4번 학생의 점수: " + scoreArray[3]);
    }
}
```
- 실행 결과
```java
1번 학생의 점수: 80
2번 학생의 점수: 90
3번 학생의 점수: 100
4번 학생의 점수: 70
```

### 6.1.4 배열에서 반복문 사용하기
- 반복문으로 배열 출력하기
```java
public class Main {
    public static void main(String[] args) {
        int[] scoreArray = {80, 90, 100, 70};
        scoreArray[0] = 50;
        scoreArray[1] = 60;
        scoreArray[2] = 70;
        scoreArray[3] = 80;
        for (int i = 0; i < 4; i++) {
            System.out.println(i + 1 + "번 학생의 점수: " + scoreArray[i]);
        }
    }
}
```
- 실행 결과
```java
1번 학생의 점수: 50
2번 학생의 점수: 60
3번 학생의 점수: 70
4번 학생의 점수: 80
```

- 배열 크기로 범위 지정하기
- 배열명.length : 배열의 크기를 알 수 있는 속성
  - 배열에 저장된 값의 개수가 아니라 **저장할 수 있는 최대 개수**
  - 예시
    ```java
    public class Main {
        public static void main(String[] args) {
            int[] intArr = new int[5];
            intArr[0] = 10;
            intArr[1] = 20;
            intArr[2] = 30;
            intArr[4] = 40;
            System.out.println("배열 크기: " + intArr.length);
        }
    }
    ```
  - 실행 결과
    ```java
    배열 크기: 5
    ```
- for문 통해서 배열의 크기로 출력하기
```java
public class Main {
    public static void main(String[] args) {
        int[] scoreArray = {80, 90, 100, 70};
        scoreArray[0] = 50;
        scoreArray[1] = 60;
        scoreArray[2] = 70;
        scoreArray[3] = 80;
        for (int i = 0; i < scoreArray.length; i++) {
            System.out.println(i + 1 + "번 학생의 점수: " + scoreArray[i]);
        }
    }
}
```
- 실행 결과
```java
1번 학생의 점수: 50
2번 학생의 점수: 60
3번 학생의 점수: 70
4번 학생의 점수: 80
```

## 6.2 이차원 배열
- 이차원 배열 : 행과 열로 구성되며 배열 안에 배열이 존재하는 형태

### 6.2.1 이차원 배열 선언하고 초기화하기
- 이차원 배열 선언할 때는 대괄호 2개([][])를 사용
- 초기화 하는 방법
1. 배열을 선언할 때 직접 값을 넣어 초기화
- 이차원 배열 안에 일차원 배열이 값으로 들어가 있는 형태
```java
자료형[][] 배열명 = {{값1, 값2, ...},{값1, 값2, ...}};
```
- 예시
```java
int[][] arr2 = {{0,1,2}, {3,4,5}, {6,7,8}};
```

2. 배열 크기로 생성하는 방법
- new 키워드를 사용하고 자료형 뒤에 행과 열의 크기를 각각 명시
- 행은 가로, 열은 세로로 표현
```java
자료형[][] 배열명 = new 자료형[행_크기][열_크기];
```
- 예시
```java
int[][] arr2 = new int[3][3]
```
- 3*3 이차원 배열을 의미함

### 6.2.2 이차원 배열에 접근하기
- 행과 열의 인덱스를 사용
```java
배열명[행_인덱스][열_인덱스];
```
![alt text](<이차원 배열의 인덱스.png>)
- 이차원 배열을 순회하기 위해서는 인덱스가 2개라 중첩 반복문을 사용해야함
  - 첫번째 for문에서는 행 인덱스를 두번째 for문에서는 열 인덱스를 통해 배열에 접근
- matrix.length는 행의 수를 나타냄
- matrix[0].length는 matrix 배열에서 첫번째 행의 열 개수를 나타냄
- matrix[0].length는 matrix 배열에서 두번째 행의 열 개수를 나타냄
- 예시
```java
public class Main {
    public static void main(String[] args) {
       int[][] matrix = new int[3][3];
        matrix[0][0] = 1;
        matrix[0][1] = 2;
        matrix[0][2] = 3;
        matrix[1][0] = 4;
        matrix[1][1] = 5;
        matrix[1][2] = 6;
        matrix[2][0] = 7;
        matrix[2][1] = 8;
        matrix[2][2] = 9;

        for (int i=0; i < matrix.length;i++){
            for (int j = 0; j < matrix[0].length; j++){
                System.out.print(matrix[i][j]+ " ");
            }
            System.out.println(""); // 행 바꿈을 위해 줄 바꿈 추가
        }
    }
}
```
- 실행 결과
```java
1 2 3 
4 5 6 
7 8 9 
```

- 반복문을 통해 이차원 배열에 값을 저장하기
  - matrix[행_인덱스][열_인덱스] = 값;
  - 행 인덱스는 i 변수로, 열 인덱스는 j 변수로 치환
  - 1부터 9까지 할당할 값이 1씩 증가 => 변수 x로 표현
    - 반복문 밖에서 x를 초기화해야함
    - 반복문 안에 하면 반복문이 돌 때마다 초기화됨
```java
public class Main {
    public static void main(String[] args) {
       int[][] matrix = new int[3][3];
       int x = 1;
       for (int i = 0 ; i < matrix.length ; i++){
           for (int j = 0 ; j < matrix[0].length ; j++)
               matrix[i][j] = x++;
       }

        for (int i=0; i < matrix.length;i++){
            for (int j = 0; j < matrix[0].length; j++){
                System.out.print(matrix[i][j]+ " ");
            }
            System.out.println(""); // 행 바꿈을 위해 줄 바꿈 추가
        }
    }
}
```
- 실행 결과
```java
1 2 3 
4 5 6 
7 8 9 
```

## 6.3 배열 심화
### 6.3.1 참조 자료형으로서의 배열
- 참조 : 실제 값이 아닌 주소를 저장하는 것
- 참조 변수 : 메모리 주소를 저장하는 변수
- 참조 자료형 예시 : 배열, 문자열
- 자바의 메모리 구조
  - 자바 프로그램이 JVM을 통해 실행되면 운영체제로부터 프로그램을 실행하는데 필요한 메모리를 할당받음
  - 런타임 데이터 영역 : 할당 받은 메모리 영역
  - ![alt text](<런타임 데이터 영역.png>)
  - 일반 변수(기본 자료형 변수)는 스택에 값 자체를 저장
  - **참조 변수는 스택에 할당되고 실제 값은 힙에 저장**
    - 참조 변수는 저장된 주소를 통해 힙의 값에 접근

- 예시
```java
int[] numbers = new int[5];
```
- new 키워드를 통해 힙에 새로운 공간을 할당하고 할당된 공간에 배열을 생성
- 크기가 5인 int형 배열 생성 => int형은 4바이트이기 때문에 4*5 = 20 바이트의 연속된 메모리 공간이 하당됨
- new 키워드는 힙에 생성된 배열의 첫번째 요소의 주소를 반환 => 반환된 주소는 스택 영역에 있는 numbers 변수에 저장
- numbers 변수는 저장된 주소로 배열의 요소에 접근
  - 힙의 주소 값을 가진 참조 변수는 스택에 할당되고 실제 값은 힙에 저장됨

![alt text](<기본 변수와 참조 변수의 메모리 구조 비교.png>)
- numbers 변수에 저장된 0*200은 배열의 첫번째 요소가 저장된 주소

### 6.3.2 배열의 복사
- 일반 변수일 때
```java
int a = 1;
int b = a; // b의 값은 1
```
  - 기본 자료형은 값 자체를 복사하기 때문에 b의 변수 값이 1이 됨
  - 이후 a의 변수의 값을 변경해도 b 변수의 값에는 영향을 미치지 않음

- 참조 변수일 때
```java
public class Main {
    public static void main(String[] args) {
        int[] originArray = {1, 2, 3};
        int[] copyArray = originArray;
        copyArray[0] = 10;
        System.out.println(copyArray[0]); // 1
        System.out.println(copyArray[1]); // 2
        System.out.println(copyArray[2]); // 3
    }
}
```
- 실행 결과
```java
10
2
3
```
- 얕은 복사 : 배열을 복사했을 때 동일한 배열을 가르키는 것, 배열의 참조인 주소만을 복사
- 얕은 복사를 한 경우 한쪽에서 값을 변경했을 때 다른 쪽에도 영향을 미침
  - 원본 배열과 독립적인 복사본이 필요하면 얕은 복사가 아닌 **깊은 복사**를 사용해야함


- 깊은 복사 : 배열의 모든 요소를 복사해 새로운 배열을 생성, 원본 배열과 별개로 깊은 복사된 배열은 별도의 메모리 공간에 존재함, 한쪽을 수정해도 다른 쪽에 영향을 미치지 않음
  - 깊은 복사를 하는 가장 쉬운 방법은 모든 요소를 하나씩 복사하는 것
```java
public class Main {
    public static void main(String[] args) {
        int[] originArray = {1, 2, 3};
        int[] deepCopy = new int[originArray.length];
        for (int i = 0; i < originArray.length; i++){
            deepCopy[i] = originArray[i];
        }
        deepCopy[0] = 10;
        System.out.println(originArray[0]);
        System.out.println(deepCopy[0]);
    }
}
```
- 실행 결과
```java
1
10
```
## 셀프 체크
```java
public class Main {
    public static void main(String[] args) {
       int [][] scoreArray = {
               {85, 70, 90, 95},
               {80, 95, 90, 75},
               {75, 85,90, 80}
       };
        System.out.println("학생들의 성적은 다음과 같습니다.");
       for (int i=0; i<scoreArray.length; i++){
           int sum = 0;
           System.out.print("학생" + (i+1)+ " ");
           for (int j=0; j<scoreArray[0].length; j++){
               sum+=scoreArray[i][j];
           }
           double average = (double) sum / scoreArray[i].length;
           System.out.print("| 평균: " + average+ "\n");
       }
    }
}
```
- 실행 결과
```java
학생들의 성적은 다음과 같습니다.
학생1 | 평균: 85.0
학생2 | 평균: 85.0
학생3 | 평균: 82.5
```
- 유의점
파이썬과 달리 자료형이 매우 중요하여 굉장히 헤매고 어려웠다. 원래는 배열의 마지막에 average를 넣으려고 했으나 출력 형태가 소수점이라서 자료형이 달라 함께 넣어지지 않았다. 도저히 모르겠어서 답을 참고 해봤을 때 내가 틀렸던 점은 다음과 같다.
1. sum의 초기화 위치
for문 밖에서 sum을 초기화 했는데 이렇게 되면 다음 학생에 해당되면 sum이 초기화되지 않아 맞지 않은 sum 값이 나오게 된다. 자꾸 초기화 위치를 틀리는데 신경 써야한다.
2. 프린트 방식은 println을 꼭 쓰지 않고 여러가지 서식지정자나 개행문자를 통해서도 출력할 수 있다. 보이는 형태에 너무 한정되지 말자
3. 자바에서는 자료형이 다르면 새로운 변수에 저장을 해줘야 한다.
