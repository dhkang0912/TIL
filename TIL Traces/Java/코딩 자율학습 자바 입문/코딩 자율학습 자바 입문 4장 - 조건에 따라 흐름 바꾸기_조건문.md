# 4장 조건에 따라 흐름 바꾸기: 조건문
## 4.1 조건이 하나일 때: if-else
- 조건문 : 조건에 따라 실행하는 명령
  - ```
    if (조건) {
        실행문; // 조건을 만족할 때 실행할 명령문
    } else {
        실행문; // 조건을 만족하지 않을 때 실행할 명령문
    }
    ```
  - 조건을 만족하지 않을 때 실행할 명령문이 없으면 else 블록은 생략해도 됨
  - 실행할 명령문이 하나일 때는 중괄호를 생략해도 됨
    - 예시
    ```java
    if (score > 90)
        System.out.println("A학점");
    else
        System.out.println("A학점이 아닙니다");
    ```

### 4.1.1 조건을 만족할 때

public class Main {

}

## 4.2 조건이 여러 개일 때: else if
- if-else : 조건이 하나이고 만족하는 경우와 아닌 경우
- if-else + else if : 조건이 여러개 일 때
```
if(조건 1) {
    실행문; // 조건 1을 만족할 때 실행할 명령문
} else if (조건 2) {
    실행문; // 조건 2를 만족할 때 실행할 명령문
} else if (조건 3) {
    실행문; // 조건 3을 만족할 때 실행할 명령문
} else {
    실행문; // 조건을 모두 만족하지 않을 때 실행할 명령문
}
```
- else if 블록은 조건 개수에 따라 여러번 사용할 수 있음
- 하지만 if문 없이 else if만 사용할 수는 없음
- 마지막은 모든 조건이 만족하지 않는 경우인 else 블록을 사용

- 예시 : 90점 이상 A학점, 80점 이상 90점 미만 B학점, 70점 이상 80점 미만 C학점, 그 외는 D학점
![!\[alt text\](image.png)](<학점 출력 코드의 순서도.png>)
- java는 조건을 `80 <= score < 90` 과 같이 적을 수 없고 나눠서 적은 후 `&&`라는 논리연산자로 작성하여 모두 만족하는 경우의 조건을 적을 수 있음
```java
public class Main {
    public static void main(String[] args) {
        int score = 80;
        if (score >= 90){
            System.out.println("A학점입니다.");
        } else if (score < 90 && score>=80 ){
            System.out.println("B학점입니다.");
        } else if (score < 80 && score>=70 ){
            System.out.println("C학점입니다.");
        } else {
            System.out.println("D학점입니다.");
        }
    }
}
```
- 실행 결과
```
B학점입니다.
```

## 4.3 조건문 안에 조건문이 있을 때: 중첩 조건문
- 중첩 조건문 : 조건문이 중첩되어있는 조건문
- 예시 : 4학년에게는 점수가 90점 이상이면 장학금을 지급
  - 학년을 먼저 확인하고 해당 학년에 점수를 확인해야 장학금 지급 대상자인지를 확인할 수 있음
![Alt text](<장학금 지급 대상자 확인 코드의 순서도.png>)
- 학년을 확인하는 if문 안에 점수를 확인하는 if문이 중첩되어있음 => 중첩 조건문

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("학년을 입력하세요.");
        Scanner scanGrade = new Scanner(System.in);
        int grade = scanGrade.nextInt(); // 학년을 입력받기

        if (grade == 4){
            System.out.println("점수를 입력하세요.");
            Scanner scanScore = new Scanner(System.in);
            int score = scanScore.nextInt(); // 점수 입력받기

            if (score >= 90){
                System.out.println("장학금 지급 대상입니다.");
            } else {
                System.out.println("장학금 지급 대상이 아닙니다.");
            }
        } else {
            System.out.println("장학금 지급 학년이 아닙니다.");
        }

    }
}
```
- 실행 결과
```java
학년을 입력하세요.
4
점수를 입력하세요.
95
장학금 지급 대상입니다.
```
- 조건의 범위를 잘 파악하면 중첩 조건문을 쉽게 작성할 수 있으나 코드가 복잡해지기 때문에 3개 이상은 사용하지 않는 것이 좋음


## 4.4 조건과 일치하는 값 찾기: switch
- switch : if-else 문처럼 조건에 따라 실행할 명령어가 달라짐
- 기본 형식
```
swich (조건) {
    case (값1):
        실행문;
        break;
    case (값1):
        실행문;
        break;
        ...
    default: // 생략 가능
        실행문;
        break;
}
```
- switch 키워드 다음에 소괄호를 붙이고 그 안에 조건이 들어감
- 중괄호 안 조건과 비교할 값을 가진 여러 case 블록이 있음, 비교할 값의 개수에 따라 달리짐
  - case 키워드 뒤에 비교할 값을 적고 :을 붙임
  - 값은 조건과 같은 자료형이어야 함
  - case 블록 끝에는 break가 들어감 => 조건을 만족할 때 switch 문을 탈출
- 만약 일치하는 case 블록이 없다면 default 블록으로 가서 명령문 실행
  - default 블록은 생략 가능
  - default 블록이 실행되면 switch 문은 종료되므로 break 생략 가능
  - switch 문 안에 어느 위치에 작성해도 됨
- 범위가 아닌 정확한 값으로만 비교 가능
- case 블록에 break를 넣지 않으면 다음 case도 확인하게 됨
```java
public class Main {
    public static void main(String[] args) {
        System.out.println("숫자를 입력하세요");
        Scanner scanNum = new Scanner(System.in);
        int num = scanNum.nextInt(); // 학년을 입력받기

        switch (num){
            case (1):
                System.out.println("1");
                break;
            case (2):
                System.out.println("2");
                break;
            case (3):
                System.out.println("3");
                break;
            default:
                System.out.println("입력값이 1, 2, 3 중 없습니다");
        }
    }
}
```
- 실행 결과
```java
숫자를 입력하세요
100
입력값이 1, 2, 3 중 없습니다
```
```java
숫자를 입력하세요
1
1
```

## 4.5 삼항 연산자
- 삼항 연산자 : 조건을 한 줄로 작성하여 코드 줄 수를 줄일 수 있음
```
(조건) ? A : B
```
| 구분  |                       의미                       |
| :---: | :----------------------------------------------: |
| 조건  | true 또는 false 값을 반환하는 조건이 들어갑니다. |
|   A   |       조건의 결과가 true일 때 선택합니다.        |
|   B   |       조건의 결과가 false일 때 선택합니다.       |

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("점수를 입력하세요. (예: 95, 90, 85, 80)");
        Scanner scan = new Scanner(System.in);
        int input = scan.nextInt(); // 학년을 입력받기

        String grade = (input >= 90) ? "A" : "B";
        System.out.println(grade + "학점입니다.");
    }
}
```
- 실행결과
```java
점수를 입력하세요. (예: 95, 90, 85, 80)
85
B학점입니다.
```
- 삼항 연산자를 활용하면 코드의 줄 수가 줄어들지만 무분별하게 사용하면 코드 읽기가 어려워지니 주의해야 함

## 셀프체크
- 조건
1. 알파벳 소문자를 입력받아 대문자로 변환해 출력하는 프로그램을 switch 문으로 작성
2. a, b, c 외 다른 문자를 입력받으면 일치하는 알파벳이 없다고 출력하고 switch 문 종료
```java
public class Main {
    public static void main(String[] args) {
        System.out.println("알파벳 소문자를 입력해주세요.");
        Scanner input = new Scanner(System.in);
        String alpabet = input.next();
        switch (alpabet){
            case ("a"):
                System.out.println("A");
                break;
            case ("b"):
                System.out.println("B");
                break;
            case ("c"):
                System.out.println("C");
                break;
            default:
                System.out.println("일치하는 알파벳이 없습니다.");
        }
        input.close();
    }
}
```
- 주의점
  - `input.next()`, `input.nextline()` : next()는 띄어쓰기 전까지 단어를 입력받고 nextline()은 엔터 전까지 입력한 모든 내용을 인풋 받음
  - 로직 모두 종료됐으면 메모리 낭비되지 않도록 Scanner 닫아주기
