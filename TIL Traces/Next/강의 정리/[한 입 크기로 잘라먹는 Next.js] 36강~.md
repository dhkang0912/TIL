## 36강 앱 라우터의 데이터 페칭
- 페이지 라우팅에서는 모든 컴포넌트가 클라이언트 컴포넌트이기 때문에 서버에서만 실행되는 함수를 통해서 서버 렌더링을 진행함
  - 최상단의 컴포넌트에서 하단의 모든 페이지들 다 렌더링되어야 함

### 앱 라우터에서 데이터 페칭
- 서버 컴포넌트를 비동기 함수로 작성하여 데이터 페칭
- 클라이언트 컴포넌트에는 브라우저 동작 시 문제를 일으킬 수 있기 때문에 Async 키워드를 사용할 수 없었음
- 데이터가 필요한 경우 해당 컴포넌트에서 직접 데이터를 불러올 수 있음
